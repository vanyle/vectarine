Module for 4D vectors.
4D vectors can represent colors and 3D rotations.
You can use them for 3D by ignoring the last component.

## Functions

### vec4.fromRotation

```luau showLineNumbers=false
vec4.fromRotation(axis: Vec4, angle: number): Vec4
```

Returns a quaternion representing a rotation of `angle` radians around the given axis
The 4th component of the axis is ignored, it is treated as a 3d vector.
The length of the result is always 1.
