### physics.newVoxelCollider

```luau showLineNumbers=false
physics.newVoxelCollider(
	voxelSize: Vec.Vec2,
	voxelsData: Tile.TilemapResource | Tile.GeneratedTilemap,
	layer: number,
	low: Vec.Vec2,
	high: Vec.Vec2,
	filledTileIds: { number },
): Collider2
```

Create a voxel collider
A voxel collider is a efficient representation of a 2D grid of square colliders.
If the tilemap resource is not loaded, this will produce an error.
It is useful for building levels.
You can split your terrain in parts and use multiple voxel colliders to have infinite terrain if needed.

You can create multiple voxel colliders on the same region with different filledTileIds to have different objects react differently to entities (for example, wall block the player, spikes hurt them, etc.)

**Parameters**

- `voxelSize` ([`Vec.Vec2`](/references/vec/#vec2)): Vec2 The size of a single voxel
- `voxelsData` (`Tile.TilemapResource | Tile.GeneratedTilemap`): TilemapResource A tilemap resource containing the data of the voxels. The tileId of each voxel will be used to determine if it is filled or not.
- `layer` (`number`): number The layer of the tilemap resource to use for the voxels data
- `low` ([`Vec.Vec2`](/references/vec/#vec2)): Vec2 The lowest coordinate of the voxel collider in the tilemap, it is rounded down to get an integer coordinate.
- `high` ([`Vec.Vec2`](/references/vec/#vec2)): Vec2 The highest coordinate of the voxel collider in the tilemap, it is rounded down to get an integer coordinate.
- `filledTileIds` (`{ number }`): \{ number \} A list of tileIds that are considered filled and will be colliders. All other tileIds will be considered empty and won't have colliders.

```luau showLineNumbers=false

	position: Vec.Vec2,
	direction: Vec.Vec2,
	maxTimeOfImpact: number?,
): { { object: Object2, timeOfImpact: number } }
```

Get all objects intersecting a ray. The direction does not have to be normalized and represents the "velocity" of the ray.
For performance reasons, you should set a maximum time of impact which is the maximum time the ray will travel at its speed.
The time of impact is the time the ray will travel to reach the object. For normalized directions, this is the distance.

### World2:createObject

```luau showLineNumbers=false
World2:createObject(
	position: Vec.Vec2,
	mass: number,
	collider: Collider2,
	tags: { string },
	bodyType: "static" | "dynamic" | "kinematic",
): Object2
```

Create a new object into the world. Objects are specific to a given world.
You can give the object tags to find it later
Objects can have 3 body types:
- static: objects never move (like the ground)
- dynamic: objects that move and react to collisions (player, enemies, pushable crates, etc.)
- kinematic: objects that can be manually moved with code but cannot be moved by other objects (like moving platforms or elevators)

**Parameters**

- `position` ([`Vec.Vec2`](/references/vec/#vec2)): Vec2
- `mass` (`number`): number Must be greater than 0
- `collider` ([`Collider2`](/references/physics/#collider2)): Collider
- `tags` (`{ string }`): \{ string \}
- `bodyType` (`"static" | "dynamic" | "kinematic"`): "static" | "dynamic" | "kinematic"

**Returns** Object2
