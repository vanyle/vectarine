### UI module

This module provides the building blocks for creating user interfaces for your games.
It is made for game interfaces and is thus very flexible to allow you to create playful and unique interfaces.

The core concept is a [`Widget`](/references/ui/#widget), which is a rectangular area on the screen which has a size and can be drawn.

The main widget is the Generic widget obtained using the [`ui.widget`](/references/ui/#uiwidget) function which is drawn using a function you provide.

You can compose widgets together using the [`ui.column`](/references/ui/#uicolumn), [`ui.row`](/references/ui/#uirow) and [`ui.stack`](/references/ui/#uistack) widgets.

Widgets are immutable: once they are created, you cannot change their content.
Use the generic widget and its draw function to create dynamic widgets that can react to game state or user input.
For example, you can wrap a column widget inside a generic widget to change its content by creating a new column widget and drawing it when changes are needed.

### ui.widget

```luau showLineNumbers=false
ui.widget<T>(size: vec.Vec2, drawFn: (event: EventState, extra: T) -> ()): Widget<T>
```

Create a generic widget with a fixed preferred size and a custom draw function.
Can be used to create custom widgets or draw parts of the game in the UI.
Can also be used for buttons, or to make part of the UI react to events

**Parameters**

- `size` ([`vec.Vec2`](/references/vec/#vec2)): Vec.Vec2 — the preferred size of this widget or a function that returns the preferred size
- `drawFn` (`(event: EventState, extra: T) -> ()`): (event: EventState, extra: T) -> () — called to draw the widget content

### ui.column


Create a column (vertical layout) that stacks its children top to bottom.
The column's preferred size accounts for children sizes, gap between them, and padding.
Children are drawn from top to bottom in the order provided.

**Parameters**

- `options` ([`ContainerOptions`](/references/ui/#containeroptions)): ContainerOptions — optional padding and gap
- `children` (`{ Widget<T> }`): \{ Widget&lt;T> \} — ordered list of child widgets


Create a spacer widget that takes up space but does not draw anything.
This can be used to create gaps between widgets or to push widgets apart.

### ui.text

```luau showLineNumbers=false
ui.text<T>(
	text: string | ((event: EventState, extra: T) -> string),
	options: TextOptions<T>,

```

Create a text widget that draws the given text. The size of the text is computed such that
the text fits on a single line within the given size.
The `getText` function is called each frame to get the text to draw and its color. You can use it to dynamically
change the text without needing to wrap the text widget in a generic widget.

### ui.scrollableArea

```luau showLineNumbers=false
ui.scrollableArea<T>(
	viewSize: vec.Vec2,
	content: Widget<T>,
	drawScrollbar: ((info: ScrollbarInfo) -> number)?,
): Widget<T>
```

Create a scrollable area that shows a portion of its content and allows *vertical* scrolling to see the rest.
If the content is smaller than the view size, the content is shown fully, centered and no scrollbar is shown.
If the content is larger than the view size, mouse wheel scrolling is enabled.
The optional `drawScrollbar` function is called each frame (only when scrolling is needed) to draw a custom scrollbar.
It receives a [`ScrollbarInfo`](/references/ui/#scrollbarinfo) table with the current scroll state. Drawing coordinates are in the scrollable area's local space.

**Parameters**

- `content` (`Widget<T>`): Widget — the content widget to scroll
- `viewSize` ([`vec.Vec2`](/references/vec/#vec2)): Vec.Vec2 — the visible area size
- `drawScrollbar` (`((info: ScrollbarInfo) -> number)?`): ((info: ScrollbarInfo) -> number)? — optional custom scrollbar drawing function that receives the current scroll state and returns the desired scrollbar ratio.

### ui.stack

```luau showLineNumbers=false
ui.stack<T>(options: StackOptions, content: { Widget<T> }): Widget<T>
```

Create a stack that places its children on top of each other. The size of the stack is the maximum size of its children.
Children are drawn in the order provided, so the first child is on the bottom and the last child is on the top.
This can be used to show text with a background image for example, or to draw text twice for a shadow effect.

**Parameters**

- `options` ([`StackOptions`](/references/ui/#stackoptions)): StackOptions — optional alignment of children within the stack

### ui.slider

```luau showLineNumbers=false
ui.slider<T>(
	size: vec.Vec2,
	options: SliderOptions,
	track: Widget<T>,
	handle: Widget<T>,
): Widget<T>
```

Create a slider widget that allows the user to select a value by horizontally dragging a handle along a track.
You need to pass a track and handle widget to provide the appearance of the slider.

### ui.tabs

```luau showLineNumbers=false
ui.tabs<T>(tabs: { [string]: Widget<T> }): TabWidget<T>
```

Create a tab widget that allows switching between different child widgets using setActiveTab.
The [`tabs`](/references/ui/#uitabs) widgets provides built-in animations when switching tabs.
The tabs widget has the size of the widget it is currently displaying.
The [`tabs`](/references/ui/#uitabs) parameter is a table mapping tab names to widgets.
By default, widget corresponding to the "" tabName is shown. If there is no "" tab, another tab is picked in an unspecified manner.

### ui.withDebugOutline

```luau showLineNumbers=false
ui.withDebugOutline<T>(drawFn: () -> (), toggle: boolean?): ()
```

Debugging function that makes all widgets drawn inside to show a debugging outline.
This can be used to visualize the layout of widgets and understand what is taking up space on the screen.
You can set toggle to true / false to quickly enable or disable the outline.

#### ContainerOptions.padding

Padding around the container's content. Can be a single number (uniform on all sides)
or a table with optional top/bottom/left/right fields. Defaults to 0.

#### ContainerOptions.gap

```luau showLineNumbers=false
gap: number?
```

Distance between children. Defaults to 0.

#### ContainerOptions.align

```luau showLineNumbers=false
align: ("start" | "center" | "end")?
```

Cross-axis alignment of children, similar to CSS `align-items`.
For a column: aligns children horizontally ("start" = left, "center", "end" = right).
For a row: aligns children vertically ("start" = bottom, "center", "end" = top).
Defaults to "start".
