### Graphics

Functions to draw shapes, images, and canvases to the screen.

Uses Vec or Coord types for position and directions.


### graphics.drawWithMask

```luau showLineNumbers=false
graphics.drawWithMask(drawFunction: () -> (), maskFunction: () -> ()): ()
```

Runs drawFunction using the result of the maskFunction as a mask.
drawFunction will only be able to draw in places where maskFunction drew.
The output of maskFunction is not visible directly and the colors used by the mask do not matter.

This can be useful to crop images or scenes to specific shapes like a circle.

### graphics.drawSplashScreen

```luau showLineNumbers=false
graphics.drawSplashScreen(loadingText: string?, progress: number?): ()
```

Show a splash screen over the whole screen. This is useful to show a loading animation while the game is loading.
You can configure your splash screen using the `loading_animation` field in the `.vecta` manifest.
Optionally, you can pass some text to show during loading and a number between 0 and 1 to show a progress bar.

### graphics.drawSplashScreenIfNeeded

```luau showLineNumbers=false
graphics.drawSplashScreenIfNeeded(
	resourcesToWaitFor: { Resource.Resource },
	loadingText: string?,
): boolean
```

Show a splash screen if any of the resources are not ready.
A progress bar is automatically shown based on the number of resources needed.
Optionally, you can pass some text to show during loading.
Returns true if the splash screen is shown.
You can use it like this:
```luau
function Update()
    if module.showSplashScreenIfNeeded({
        resource1, resource2, resource3
    }, "Starting...") then
        return
    end
    -- Your game code requiring the resources here
end
```

### graphics.withTransformation

```luau showLineNumbers=false
graphics.withTransformation(
	transformation: { translation: Vec.Vec2?, scale: Vec.Vec2?, rotation: number? },
	drawFunction: () -> (),
): ()
```

All drawing function called inside [`withTransformation`](/references/graphics/#graphicswithtransformation) will be transformed by the given translation, scale and rotation.
You can use this to rotate or scale things without changing your drawing code.
The translation is applied first, then the scale, and finally the rotation. You can nest multiple calls to [`withTransformation`](/references/graphics/#graphicswithtransformation) and the transformations will be combined.
The transformations are only applied for 2d drawing functions.

This is used internally to implement the UI system.

### graphics.withoutTransformation

```luau showLineNumbers=false
graphics.withoutTransformation(drawFunction: () -> ()): ()
```

Reset the transformation to the default inside the drawFunction. You can still call [`withTransformation`](/references/graphics/#graphicswithtransformation) inside the drawFunction, this just resets the transformation to the default for the duration of the drawFunction.
