## Functions

### persist.onReload

```luau showLineNumbers=false
persist.onReload<T>(defaultValue: T, globalName: string): T
```

Get a value that persist when the script is hot-reloaded. The value is stored as a global variable named `globalName`
and can be inspected in the watcher.

### persist.onReloadWithProvider

```luau showLineNumbers=false
persist.onReloadWithProvider<T>(provider: () -> T, globalName: string): T
```

Same as [`onReload`](/references/persist/#persistonreload), but instead of taking a default value, it takes a provider function.
This is useful if the default value is expensive to create so it is not created on hot-reload.

### persist.save

```luau showLineNumbers=false
persist.save(name: string, value: any)
```

Save `value` so that it is persisted across restarts.
You can obtain saved values using [`load`](/references/persist/#persistload).
Saving can take some time, so calling [`save`](/references/persist/#persistsave) followed by [`load`](/references/persist/#persistload) might not give the expected result.
`name` can only contain letters, numbers, underscore and dot.

### persist.load

```luau showLineNumbers=false
persist.load(name: string): any?
```

Load a saved value. If the value does not exist, return `nil`.
