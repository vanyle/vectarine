A module for creating and subscribing to events. See [`newEvent`](/references/event/#eventnewevent) for how to create and use events.

## Functions

### event.newEvent

```luau showLineNumbers=false
event.newEvent<T>(name: string): Event<T>
```

Create a new event type, for example [`newEvent("hit")`](/references/event/#eventnewevent)
The name should be unique and is used for debugging purposes.
If you try to create newEvent with the same name, you will get the same underlying event object.
You can pass any type when triggering the event and it will be forwarded to its subscribers. For example:
```luau
local hitEvent: event.Event<number> = event.newEvent("hit")
hitEvent:on("print", function(damage: number)
    print("Hit with damage: " .. damage)
end)
hitEvent:dispatch(10) -- This will print "Hit with damage: 10"
```

**Parameters**

- `name` (`string`): string The name of the event type

**Returns** EventType

Clear all previous subscriptions to the resource loaded event and return it.

The number is the ID of the resource loaded.

Returns the text input event

The string is the character that was pressed, with modifiers like shift or option.
You can use this function to implement text input.

### Event:dispatch

```luau showLineNumbers=false
Event:dispatch<T>(data: T)
```

Dispatch an event to the bus which will call all the subscribers to that event type with the data passed.

If you unsubscribe from an event during the dispatch, all the subscribers that existed at the start of the dispatch will still be called.
If you add subscribers to an event during the dispatch, they will not be called during that dispatch.

**Parameters**

- `event`: EventType&lt;T> The type of event
- `data` (`T`): T Additional event data

### Event:on

```luau showLineNumbers=false
Event:on<T>(subscriptionName: string, callback: (data: T) -> ()): SubID
```

Subscribe to an event type. When that event is triggered, the callback function will be called.
If you resubscribe using the same subscription name, the previous subscription will be removed and replaced with the new one.

**Parameters**

- `event`: EventType&lt;T> The type of event
- `callback` (`(data: T) -> ()`): fun(data: T) A function that will be called when the event is sent. The callback function will receive the event data as arguments.

**Returns** SubID A subscription ID that can be used to unsubscribe
