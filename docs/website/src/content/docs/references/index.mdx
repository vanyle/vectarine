This reference lists everything Vectarine provides to your Luau code. It is generated from the `luau-api` folder that is inside every Vectarine project, so you can also read it directly in your editor.

To use a module, import it with `require`, for example `const vec = require("@vectarine/vec")`.

## Modules

- [`audio`](/references/audio/)
- [`camera`](/references/camera/)
- [`canvas`](/references/canvas/): Functions to create canvas and shaders A canvas is a drawing surface and a shader is a program that changes how a canvas is drawn to another drawing surface.
- [`coord`](/references/coord/): A module for dealing with coordinate systems and switching between them.
- [`debug`](/references/debug/): Debugging utilities This module contains functions that help with debugging your game.
- [`event`](/references/event/): A module for creating and subscribing to events.
- [`fastlist`](/references/fastlist/): A module for writing high performance code by storing data in a compact way - A fastlist contains a list of Vec2 - Any function that takes a Vec2 and outputs another Vec2 also exists for Fastlist with the same syntax - You can index a fastlist using .get - You can draw the content of a fastlist quickly using functions starting with draw
- [`graphics`](/references/graphics/): Functions to draw shapes, images, and canvases to the screen.
- [`image`](/references/image/)
- [`io`](/references/io/)
- [`loader`](/references/loader/): Loader Functions to load external resources like images, scripts, fonts, shaders, audio, etc.
- [`persist`](/references/persist/)
- [`physics`](/references/physics/): A Physics API for 2D This API is experimental and can change.
- [`resource`](/references/resource/): Functions common to all resources A resource is an external piece of data.
- [`text`](/references/text/)
- [`tile`](/references/tile/)
- [`ui`](/references/ui/): This module provides the building blocks for creating user interfaces for your games.
- [`vec`](/references/vec/): Module for 2D vectors.
- [`vec4`](/references/vec4/): Module for 4D vectors.
