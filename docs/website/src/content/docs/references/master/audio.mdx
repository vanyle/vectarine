Plays sounds and music.

Load a sound file with [`loader.loadAudio`](/references/master/loader/#loaderloadaudio) to get an [`AudioResource`](/references/master/audio/#audioresource), then call [`AudioResource:play`](/references/master/audio/#audioresourceplay). Sounds load in the background, so
a sound that is not loaded yet stays silent and raises no error. Volume is set per sound with [`AudioResource:setVolume`](/references/master/audio/#audioresourcesetvolume).

### Example

```luau
const io = require("@vectarine/io")
const loader = require("@vectarine/loader")

const jumpSound = loader.loadAudio("audio/jump.wav")

function Update(deltaTime: number)
	if io.isKeyJustPressed("Space") then
		jumpSound:play()
	end
end
```

### Common mistakes

- Play a sound when something happens, such as a key press ([`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed)), not on every frame. Calling
  [`AudioResource:play`](/references/master/audio/#audioresourceplay) every frame does nothing while the sound plays, but it restarts the sound as soon as it ends.
- A sound that is not loaded yet is silent and raises no error. A wrong path looks the same.

## AudioResource

```luau showLineNumbers=false
export type AudioResource = ...
```

An audio resource is a playable piece of sound or music.

You get one from [`loader.loadAudio`](/references/master/loader/#loaderloadaudio). Play it with [`AudioResource:play`](/references/master/audio/#audioresourceplay), stop it with [`AudioResource:pause`](/references/master/audio/#audioresourcepause) and read
its state with [`AudioResource:isPlaying`](/references/master/audio/#audioresourceisplaying).

### AudioResource:play

```luau showLineNumbers=false
AudioResource:play(loop: boolean?, fadeIn: number?): ()
```

Plays the sound from its beginning.

A sound plays once at a time: calling [`AudioResource:play`](/references/master/audio/#audioresourceplay) while the sound is already playing does nothing. If the
sound is paused, it continues from where it was, as [`AudioResource:resume`](/references/master/audio/#audioresourceresume) does. When a non-looped sound reaches its
end, it stops, and the next call starts it from the beginning. Nothing happens if the sound is not loaded yet.

**Parameters**

- `loop` (`boolean?`): If `true`, the sound restarts when it ends, until it is paused. Defaults to `false`.
- `fadeIn` (`number?`): The time, in milliseconds, over which the volume rises from silence. Defaults to `100` when the sound starts, and to `0` when it continues after a pause.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function Update(deltaTime: number)
	music:play(true, 2000) -- background music, fading in over 2 seconds
end
```

#### See also

- [`AudioResource:pause`](/references/master/audio/#audioresourcepause): stops the sound.
- [`AudioResource:setVolume`](/references/master/audio/#audioresourcesetvolume): changes the volume.

### AudioResource:isPlaying

```luau showLineNumbers=false
AudioResource:isPlaying(): boolean
```

Returns `true` if the sound is currently playing.

It is `false` before the sound is played and when it is paused. A sound that is
fading out after [`AudioResource:pause`](/references/master/audio/#audioresourcepause) still counts as playing until the fade ends.

**Returns** True if the sound is playing.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function Update(deltaTime: number)
	if not music:isPlaying() then
		music:play()
	end
end
```

### AudioResource:getDuration

```luau showLineNumbers=false
AudioResource:getDuration(): number
```

Returns the duration of the sound in seconds.

Returns `0` if the sound is not loaded yet or failed to load.

**Returns** The duration, in seconds.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function Update(deltaTime: number)
	print(music:getDuration()) -- for example 93.5
end
```

### AudioResource:getProgress

```luau showLineNumbers=false
AudioResource:getProgress(): number
```

Returns how far the sound has played, in seconds.

It is a number between `0` and the duration given by [`AudioResource:getDuration`](/references/master/audio/#audioresourcegetduration). Use it to show a progress bar or to
synchronize the game with music.

**Returns** The time played so far, in seconds.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function Update(deltaTime: number)
	local ratio = music:getProgress() / music:getDuration()
	print(ratio) -- 0 at the start, close to 1 at the end
end
```

### AudioResource:pause

```luau showLineNumbers=false
AudioResource:pause(fadeOut: number?): ()
```

Pauses the sound.

The sound keeps its position: [`AudioResource:resume`](/references/master/audio/#audioresourceresume) or [`AudioResource:play`](/references/master/audio/#audioresourceplay) continue from there. Does nothing if the
sound is not playing.

**Parameters**

- `fadeOut` (`number?`): The time, in milliseconds, over which the volume goes down to silence before the sound pauses. The sound counts as playing until then. Defaults to `0`, which pauses at once.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function PauseGame()
	music:pause(500)
end
```

### AudioResource:resume

```luau showLineNumbers=false
AudioResource:resume(fadeIn: number?): ()
```

Continues a paused sound from where it was.

Use it after [`AudioResource:pause`](/references/master/audio/#audioresourcepause). To start a sound from the beginning, use [`AudioResource:play`](/references/master/audio/#audioresourceplay).

**Parameters**

- `fadeIn` (`number?`): The time, in milliseconds, over which the volume rises from silence. Defaults to `0`.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function ResumeGame()
	music:resume(500)
end
```

### AudioResource:setVolume

```luau showLineNumbers=false
AudioResource:setVolume(volume: number): ()
```

Sets the volume of the sound.

Use a value between `0` (silent) and `1` (full volume). Nothing
happens if the sound is not loaded yet.

**Parameters**

- `volume` (`number`): The new volume, between `0` and `1`.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

music:setVolume(0.3) -- quiet background music
```

### AudioResource:getVolume

```luau showLineNumbers=false
AudioResource:getVolume(): number
```

Returns the volume of the sound.

It is `1` until you change it with [`AudioResource:setVolume`](/references/master/audio/#audioresourcesetvolume). Returns `0` if the sound is not loaded yet.

**Returns** The volume, between `0` and `1`.

#### Example

```luau
const loader = require("@vectarine/loader")

const music = loader.loadAudio("audio/music.ogg")

function Update(deltaTime: number)
	if music:isReady() then
		music:setVolume(math.max(0, music:getVolume() - deltaTime * 0.1)) -- slowly fade out
	end
end
```
