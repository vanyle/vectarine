<Aside type="caution">This is the reference of the unreleased master version of Vectarine. Some of these features may not be available in the latest release available on GitHub (0.7.0).</Aside>

This reference lists everything Vectarine provides to your Luau code. It is generated from the `luau-api` folder that is inside every Vectarine project, so you can also read it directly in your editor.

To use a module, import it with `require`, for example `const vec = require("@vectarine/vec")`.

## Modules

- [`audio`](/references/master/audio/): Plays sounds and music.
- [`camera`](/references/master/camera/): Converts between world positions and screen positions, with a movable, rotating and zoomable camera.
- [`canvas`](/references/master/canvas/): Creates canvases, which are images you draw on, and the shaders that can change how a canvas looks when it is drawn.
- [`coord`](/references/master/coord/): Creates and converts positions and sizes written in different coordinate systems.
- [`debug`](/references/master/debug/): Prints messages and measures time to help you debug your game.
- [`event`](/references/master/event/): Provides events: named channels that let one part of your game notify others without knowing who listens.
- [`fastlist`](/references/master/fastlist/): Fast lists of 2D vectors, for processing and drawing thousands of objects at once.
- [`gamepad`](/references/master/gamepad/): Reads gamepad buttons and joysticks, and controls rumble and lights.
- [`graphics`](/references/master/graphics/): Draws shapes on the screen and transforms what is drawn.
- [`image`](/references/master/image/): Draws images and tiles loaded from image files.
- [`io`](/references/master/io/): Reads the keyboard, the mouse, touch screens and controls the game window.
- [`loader`](/references/master/loader/): Loads the external files of your game: images, audio, fonts, texts, shaders, tilesets, tilemaps and scripts.
- [`persist`](/references/master/persist/): Keeps values across hot-reloads and across game restarts.
- [`physics`](/references/master/physics/): Provides a 2D physics engine: gravity, collisions, bouncing and joints.
- [`resource`](/references/master/resource/): Follows the loading of resources, like images, sounds, fonts and texts.
- [`text`](/references/master/text/): Draws and measures text with a font.
- [`tile`](/references/master/tile/): Tilesets and tilemaps, used to draw sprite sheets and levels made of a grid of tiles.
- [`ui`](/references/master/ui/): Builds user interfaces for your games, such as menus, settings screens and inventories, from widgets that you combine.
- [`vec`](/references/master/vec/): 2D vectors, used for positions, sizes, directions and speeds.
- [`vec4`](/references/master/vec4/): Provides 4D vectors, used mostly to represent colors and rotations.
