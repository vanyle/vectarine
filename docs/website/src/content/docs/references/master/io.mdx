```luau showLineNumbers=false
const io = require("@vectarine/io")
```

Reads the keyboard, the mouse, touch screens and controls the game window.

Call these functions from `Update` to react to the player. Input functions give the state of the current frame:
a key that is held stays down for many frames, while [`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed) is `true` for one frame only. Functions that
change the window, like [`io.setFullscreen`](/references/master/io/#iosetfullscreen), ask the engine for the change, which is applied after the current frame. For gamepads, see the [`gamepad`](/references/master/gamepad/) module.

### Example

```luau
const io = require("@vectarine/io")

local x = 0
function Update(deltaTime: number)
	if io.isKeyDown("Right") then
		x += deltaTime
	end
end
```

### Common mistakes

- Using [`io.isKeyDown`](/references/master/io/#ioiskeydown) for a one-time action like jumping. It is `true` on every frame the key is held, so the action
  repeats. Use [`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed).
- Using key functions to read typed text. Keys are physical positions, so they ignore the keyboard layout. Use
  [`io.getTextInput`](/references/master/io/#iogettextinput).
- Expecting a window change to apply immediately. [`io.setWindowSize`](/references/master/io/#iosetwindowsize), [`io.setFullscreen`](/references/master/io/#iosetfullscreen) and [`io.centerWindow`](/references/master/io/#iocenterwindow) only
  make a request that the engine applies after the current frame.

## Functions

### io.isKeyDown

```luau showLineNumbers=false
io.isKeyDown(keycode: Scancode | string): boolean
```

Returns `true` while a key is held down.

The key is a physical location, so it does not depend on the keyboard layout. Use it for actions like moving or
jumping. To read typed text, use [`io.getTextInput`](/references/master/io/#iogettextinput). To detect the frame where the key goes down, use
[`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed).

**Parameters**

- `keycode` (`Scancode | string`): The name of the key, like `"Space"`, `"A"` or `"Left Shift"`. See [`Scancode`](/references/master/io/#scancode) for the list.

**Returns** True if the key is down. False if it is up or if the name is not a valid key name.

#### Example

```luau
const io = require("@vectarine/io")

local x = 0
function Update(deltaTime: number)
	if io.isKeyDown("Left") then
		x -= 0.5 * deltaTime
	end
end
```

#### See also

- [`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed): for actions that happen once per press.
- [`io.getKeysDown`](/references/master/io/#iogetkeysdown): to list every key held down.
- [`gamepad`](/references/master/gamepad/): for controllers.

### io.getKeyName

```luau showLineNumbers=false
io.getKeyName(keycode: Scancode | string): string?
```

Returns the name of a key as the player sees it on their keyboard layout.

Use it to tell the player which key to press. For example, [`io.getKeyName("Z")`](/references/master/io/#iogetkeyname) returns `"W"` on an AZERTY keyboard
and `"Z"` on a QWERTY keyboard.

**Parameters**

- `keycode` (`Scancode | string`): The name of the key, as in [`io.isKeyDown`](/references/master/io/#ioiskeydown).

**Returns** The name of the key, or `nil` if the name is not a valid key name or the key has no name in the current layout.

#### Example

```luau
const io = require("@vectarine/io")

local label = io.getKeyName("W")
print("Press " .. (label or "?") .. " to jump")
```

### io.getTextInput

```luau showLineNumbers=false
io.getTextInput(): string
```

Returns the text typed by the player since the last frame.

Use it for text fields, names and chat. It follows the keyboard layout and handles accents and upper case. To check
if a key is pressed for an action, use [`io.isKeyDown`](/references/master/io/#ioiskeydown) instead.

**Returns** The characters typed since the last frame. It is an empty string when nothing was typed.

#### Example

```luau
const io = require("@vectarine/io")

local name = ""
function Update(deltaTime: number)
	name ..= io.getTextInput()
	if io.isKeyJustPressed("Backspace") then
		name = string.sub(name, 1, -2)
	end
end
```

#### See also

- [`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed): for key presses that trigger actions.

### io.isKeyJustPressed

```luau showLineNumbers=false
io.isKeyJustPressed(keycode: Scancode | string): boolean
```

Returns `true` during the frame where a key goes down.

It stays `false` while the key is held, so use it for actions that must trigger once per press, like jumping or
opening a menu. Keys are physical locations and do not depend on the keyboard layout: `"Q"` is always the key at
the top-left letter position, even on AZERTY. Do not use it for typing text, see [`io.getTextInput`](/references/master/io/#iogettextinput).

**Parameters**

- `keycode` (`Scancode | string`): The name of the key, like `"Space"`. See [`Scancode`](/references/master/io/#scancode) for the list.

**Returns** True if the key was pressed this frame. False if the name is not a valid key name.

#### Example

```luau
const io = require("@vectarine/io")

local jumps = 0
function Update(deltaTime: number)
	if io.isKeyJustPressed("Space") then
		jumps += 1
	end
end
```

#### See also

- [`io.isKeyDown`](/references/master/io/#ioiskeydown): for actions that last while the key is held.
- [`io.getTextInput`](/references/master/io/#iogettextinput): for typing text.

### io.getKeysDown

```luau showLineNumbers=false
io.getKeysDown(): { Scancode }
```

Returns the names of all the keys that are currently held down.

Use it to find the name of a key, or to build a "press any key" screen. The order of the keys is not specified.

**Returns** A new list of key names. It is empty when no key is down.

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	for _, key in io.getKeysDown() do
		print("Down: " .. key)
	end
end
```

### io.getMouse

```luau showLineNumbers=false
io.getMouse(): Vec.Vec2
```

Returns the position of the mouse cursor.

The position is in screen coordinates: (-1, -1) is the bottom left, (1, 1) the top right and (0, 0) the center of the
screen.

**Returns** The position of the mouse as a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	local mouse = io.getMouse()
	print(mouse.x, mouse.y) -- 0 0 when the cursor is at the center
end
```

#### See also

- [`io.getMouseState`](/references/master/io/#iogetmousestate): to know which buttons are down.
- [`io.getCurrentTouches`](/references/master/io/#iogetcurrenttouches): for touch screens.

### io.getMouseState

```luau showLineNumbers=false
io.getMouseState(): {
```

Returns which mouse buttons are down or were just pressed.

The `isLeftDown` and `isRightDown` fields are `true` while the button is held. The `isLeftJustPressed` and
`isRightJustPressed` fields are `true` only during the frame where the button goes down. Use [`io.getMouse`](/references/master/io/#iogetmouse) for the
position.

**Returns** A table with the fields `isLeftDown`, `isRightDown`, `isLeftJustPressed` and `isRightJustPressed`.

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	if io.getMouseState().isLeftJustPressed then
		print("Clicked at", io.getMouse())
	end
end
```

#### See also

- [`io.getMouse`](/references/master/io/#iogetmouse): the position of the cursor.

### io.getMouseWheel

```luau showLineNumbers=false
io.getMouseWheel(): Vec.Vec2
```

Returns how much the mouse wheel was scrolled since the last frame.

The `x` component is the horizontal scroll and the `y` component is the vertical scroll. Most mice have no
horizontal scroll, so `x` is usually 0. Both are 0 when the wheel did not move.

**Returns** The scroll amount as a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const io = require("@vectarine/io")

local zoom = 1
function Update(deltaTime: number)
	zoom += io.getMouseWheel().y * 0.1
end
```

### io.getCurrentTouches

```luau showLineNumbers=false
io.getCurrentTouches(): { Touch }
```

Returns all the fingers that are currently touching the screen.

Use [`Touch.id`](/references/master/io/#touchid) to follow the same finger from one frame to the next. The list is empty when nothing touches the
screen, and on devices without a touch screen.

**Returns** A new list of [`Touch`](/references/master/io/#touch).

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	for _, touch in io.getCurrentTouches() do
		print(touch.id, touch.position.x, touch.position.y)
	end
end
```

### io.setWindowSize

```luau showLineNumbers=false
io.setWindowSize(width: number, height: number): ()
```

Asks to change the size of the window.

On desktop, the window is resized to the requested size. On the web and in the editor, the game keeps the
requested aspect ratio and black borders are added where needed.

**Parameters**

- `width` (`number`): The requested width, in pixels. Use a whole number that is not negative.
- `height` (`number`): The requested height, in pixels. Use a whole number that is not negative.

#### Errors

Raises an error if a size is negative or is not a number that fits in a whole number.

#### Example

```luau
const io = require("@vectarine/io")

io.setWindowSize(960, 540)
```

#### See also

- [`io.getScreenSize`](/references/master/io/#iogetscreensize): the size of the screen.
- [`io.setResizeable`](/references/master/io/#iosetresizeable): to lock the window size.

### io.isWindowMinimized

```luau showLineNumbers=false
io.isWindowMinimized(): boolean
```

Returns `true` if the window is currently minimized.

While the window is minimized, Vectarine runs much slower to save battery life and avoid using the CPU.

**Returns** True if the window is minimized.

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	if io.isWindowMinimized() then
		return
	end
end
```

### io.setFullscreen

```luau showLineNumbers=false
io.setFullscreen(fullscreen: true | false | "fullscreen" | "windowed" | "desktop"): ()
```

Asks to switch the window between fullscreen and windowed mode.

`true` and `"fullscreen"` switch to fullscreen. `false` and `"windowed"` go back to a window. `"desktop"` is
"desktop fullscreen" (also called fake fullscreen): the window covers the screen without changing the video mode.
Before calling it, you can set the window size to the size of the screen to avoid black borders.

Does nothing on the web: the game is usually embedded in a page or player which already has a fullscreen button.

**Parameters**

- `fullscreen` (`true | false | "fullscreen" | "windowed" | "desktop"`): The requested mode. Any other value is ignored.

#### Example

```luau
const io = require("@vectarine/io")

function Update(deltaTime: number)
	if io.isKeyJustPressed("F11") then
		io.setFullscreen("desktop")
	end
end
```

#### See also

- [`io.setWindowSize`](/references/master/io/#iosetwindowsize): to set the size of the window.

### io.getPlatform

```luau showLineNumbers=false
io.getPlatform(): "windows" | "macos" | "linux" | "web"
```

Returns the platform the game is running on.

Use it to adapt controls or skip features that do not exist everywhere, like [`io.setFullscreen`](/references/master/io/#iosetfullscreen) on the web.

**Returns** One of `"windows"`, `"macos"`, `"linux"` or `"web"`.

#### Example

```luau
const io = require("@vectarine/io")

if io.getPlatform() == "web" then
	print("Running in a browser")
end
```

## Types

### Scancode

```luau showLineNumbers=false
export type Scancode = ...
```

The name of a physical key on the keyboard, like `"A"`, `"Space"`, `"Left Shift"` or `"F5"`.

A scancode is a location on the keyboard, independent of the keyboard layout. `"Q"` is always the key at the
position of Q on a QWERTY keyboard, even on an AZERTY keyboard where it types A. Scancodes are the names accepted
by [`io.isKeyDown`](/references/master/io/#ioiskeydown), [`io.isKeyJustPressed`](/references/master/io/#ioiskeyjustpressed) and [`io.getKeyName`](/references/master/io/#iogetkeyname), and returned by [`io.getKeysDown`](/references/master/io/#iogetkeysdown).

### Touch

```luau showLineNumbers=false
export type Touch = ...
```

A finger touching the screen, as returned by [`io.getCurrentTouches`](/references/master/io/#iogetcurrenttouches).

#### Touch.id

```luau showLineNumbers=false
id: number
```

A stable identifier for this finger while it remains on the screen.

#### Touch.position

```luau showLineNumbers=false
position: Vec.Vec2
```

The current position in screen coordinates.

#### Touch.pressure

```luau showLineNumbers=false
pressure: number
```

The normalized pressure reported by the device.
