Reads gamepad buttons and joysticks, and controls rumble and lights.

Call [`gamepad.getGamepad`](/references/master/gamepad/#gamepadgetgamepad) to get a [`Gamepad`](/references/master/gamepad/#gamepad), or `nil` if none is connected. Then read it every frame from `Update`
with [`Gamepad:isButtonDown`](/references/master/gamepad/#gamepadisbuttondown) and [`Gamepad:getJoystickTilt`](/references/master/gamepad/#gamepadgetjoysticktilt). Always handle the `nil` case, because players may not have
a gamepad. For keyboard and mouse input, see the [`io`](/references/master/io/) module.

### Example

```luau
const gamepad = require("@vectarine/gamepad")

function Update(deltaTime: number)
	local pad = gamepad.getGamepad()
	if pad and pad:isButtonDown("a") then
		print("Jump!")
	end
end
```

### Common mistakes

- [`gamepad.getGamepad`](/references/master/gamepad/#gamepadgetgamepad) returns `nil` when no gamepad is connected, or after it was unplugged. Check for `nil` every frame.
- [`Gamepad:getJoystickTilt`](/references/master/gamepad/#gamepadgetjoysticktilt) returns raw values from `-32768` to `32767`, not numbers between `-1` and `1`. Divide them yourself
  and ignore small values, because there is no dead zone.
- [`Gamepad:isButtonDown`](/references/master/gamepad/#gamepadisbuttondown) is `true` on every frame the button is held, not only when it is pressed.

## Functions

### gamepad.getGamepadCount

```luau showLineNumbers=false
gamepad.getGamepadCount(): number
```

Returns the number of connected gamepads.

**Returns** The number of gamepads. It is `0` if none is connected.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")

print(gamepad.getGamepadCount() > 0) -- true if a gamepad is plugged in
```

### gamepad.getGamepad

```luau showLineNumbers=false
gamepad.getGamepad(gamepadIndex: number?): Gamepad?
```

Returns the gamepad at an index, or `nil` if there is none.

Calling it again with the same index returns the same gamepad, so you can call it every frame. If the gamepad was
unplugged, the index is opened again, and another gamepad may have taken it.

**Parameters**

- `gamepadIndex` (`number?`): The index of the gamepad, starting at `0`. Defaults to `0`, the first gamepad.

**Returns** The gamepad, or `nil` if no gamepad is available at this index.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")

function Update(deltaTime: number)
	local pad = gamepad.getGamepad(0)
	if pad == nil then
		return -- play with the keyboard instead
	end
	print(pad:isButtonDown("start"))
end
```

## Gamepad

```luau showLineNumbers=false
export type Gamepad = ...
```

A gamepad is an input device for games, also called a "controller".

You get one from [`gamepad.getGamepad`](/references/master/gamepad/#gamepadgetgamepad). Use it to read buttons with [`Gamepad:isButtonDown`](/references/master/gamepad/#gamepadisbuttondown) and joysticks with
[`Gamepad:getJoystickTilt`](/references/master/gamepad/#gamepadgetjoysticktilt), and to make it vibrate with [`Gamepad:rumble`](/references/master/gamepad/#gamepadrumble).

### Gamepad:isButtonDown

```luau showLineNumbers=false
Gamepad:isButtonDown(buttonName: GamepadButton | string): boolean
```

Returns `true` if a button of the gamepad is currently held down.

It is `true` on every frame while the button is held, not only on the frame it was pressed. If you need to react once
per press, remember the previous value yourself. If the name is not a valid button name, it always returns `false`.

**Parameters**

- `buttonName` (`GamepadButton | string`): The name of the button. See [`GamepadButton`](/references/master/gamepad/#gamepadbutton) for the valid names.

**Returns** True if the button is held down.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")

local wasDown = false

function Update(deltaTime: number)
	local pad = gamepad.getGamepad()
	if pad == nil then
		return
	end
	local isDown = pad:isButtonDown("a")
	if isDown and not wasDown then
		print("A was just pressed")
	end
	wasDown = isDown
end
```

#### See also

- [`io.isKeyDown`](/references/master/io/#ioiskeydown): reads the keyboard instead.
- [`Gamepad:getJoystickTilt`](/references/master/gamepad/#gamepadgetjoysticktilt): reads the joysticks.

### Gamepad:getJoystickTilt

```luau showLineNumbers=false
Gamepad:getJoystickTilt(): (vec.Vec2, vec.Vec2, vec.Vec2)
```

Returns the tilt of the two joysticks and of the two triggers of the gamepad.

It returns three vectors: the left joystick, the right joystick and the triggers (`x` is the left trigger, `y` is
the right trigger). The values are the raw values of the gamepad, not numbers between `-1` and `1`: joystick axes go from
`-32768` to `32767`, and triggers from `0` to `32767`. For the vertical axis of a joystick, negative values mean up. There
is no dead zone, so a joystick at rest may report small values: ignore values that are close to `0`. Gamepads
that have no triggers or joysticks report `0` for them.

**Returns** The pressure of the left (`x`) and right (`y`) triggers.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")
const vec = require("@vectarine/vec")

local position = vec.V2(0, 0)

function Update(deltaTime: number)
	local pad = gamepad.getGamepad()
	if pad == nil then
		return
	end
	local left = pad:getJoystickTilt()
	if math.abs(left.x) > 4000 then
		position.x += left.x / 32768 * deltaTime
	end
end
```

### Gamepad:rumble

```luau showLineNumbers=false
Gamepad:rumble(lowFrequency: number, highFrequency: number, duration: number)
```

Makes the gamepad vibrate for a short time.

The gamepad has two motors: a heavy one for low frequency vibrations and a light one for high frequency ones. Calling
it again replaces the previous vibration. Nothing happens if the gamepad does not support rumble.

**Parameters**

- `lowFrequency` (`number`): The strength of the low frequency motor, from `0` (off) to `65535` (full strength).
- `highFrequency` (`number`): The strength of the high frequency motor, from `0` (off) to `65535` (full strength).
- `duration` (`number`): How long the gamepad vibrates, in milliseconds.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")

local pad = gamepad.getGamepad()
if pad then
	-- Half strength on both motors for a quarter of a second.
	pad:rumble(32000, 32000, 250)
end
```

#### See also

- [`Gamepad:setLed`](/references/master/gamepad/#gamepadsetled): sets the color of the gamepad light.

### Gamepad:hasLed

```luau showLineNumbers=false
Gamepad:hasLed(): boolean
```

Returns `true` if the gamepad has a light that can change color.

Call it before [`Gamepad:setLed`](/references/master/gamepad/#gamepadsetled). Some gamepads, like the PlayStation ones, have a color light.

**Returns** True if the gamepad has a light whose color can be set.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")

local pad = gamepad.getGamepad()
if pad then
	print(pad:hasLed())
end
```

### Gamepad:setLed

```luau showLineNumbers=false
Gamepad:setLed(color: vec4.Vec4)
```

Sets the color of the light of the gamepad.

Only the red, green and blue components of the color are used, and the alpha is ignored. Nothing happens if the
gamepad has no light: check it with [`Gamepad:hasLed`](/references/master/gamepad/#gamepadhasled).

**Parameters**

- `color` ([`vec4.Vec4`](/references/master/vec4/#vec4)): The color of the light. Each component goes from `0` to `1`.

#### Example

```luau
const gamepad = require("@vectarine/gamepad")
const vec4 = require("@vectarine/vec4")

local pad = gamepad.getGamepad()
if pad and pad:hasLed() then
	pad:setLed(vec4.RED)
end
```

## Types

### GamepadButton

```luau showLineNumbers=false
export type GamepadButton = ...
```

The name of a gamepad button, following the layout of an Xbox gamepad.

Names are not case sensitive. Several names can designate the same button, for example `"start"` and `"options"`.
The `"a"` button is the bottom button of the four buttons on the right of the gamepad, whatever the label printed on
it. Pass a name of this type to [`Gamepad:isButtonDown`](/references/master/gamepad/#gamepadisbuttondown).
