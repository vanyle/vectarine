```luau showLineNumbers=false
const graphics = require("@vectarine/graphics")
```

Draws shapes on the screen and transforms what is drawn.

Call these functions every frame from `Update`. Positions are screen coordinates: `(-1, -1)` is the bottom left of the
screen and `(1, 1)` is the top right. Every position or size can be given as a [`Vec2`](/references/master/vec/#vec2) or as a [`ScreenPosition`](/references/master/coord/#screenposition) or
[`ScreenVec`](/references/master/coord/#screenvec) made with the [`coord`](/references/master/coord/) module. Colors are [`Vec4`](/references/master/vec4/#vec4) values from the [`vec4`](/references/master/vec4/) module, with components between `0`
and `1`. To draw images, see [`ImageResource:draw`](/references/master/image/#imageresourcedraw) in the [`image`](/references/master/image/) module. To move or scale a whole scene, see
[`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation) or the [`camera`](/references/master/camera/) module.

### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	graphics.clear(vec4.WHITE)
	graphics.drawCircle(vec.V2(0, 0), 0.2, vec4.RED)
end
```

### Common mistakes

- Positions are screen coordinates, not pixels: `(-1, -1)` is the bottom left, `(1, 1)` the top right and `(0, 0)` the
  center. The y axis goes up.
- Drawing is not kept between frames. Call [`graphics.clear`](/references/master/graphics/#graphicsclear) and draw everything again in every `Update`.

## Functions

### graphics.clear

```luau showLineNumbers=false
graphics.clear(color: Vec4.Vec4?): ()
```

Fills the whole canvas with one color.

Call it at the start of `Update` to erase what was drawn during the previous frame.

**Parameters**

- `color` (`Vec4.Vec4?`): The color to fill the canvas with. Defaults to white.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	graphics.clear(vec4.DARK_BLUE)
end
```

### graphics.drawRect

```luau showLineNumbers=false
graphics.drawRect(pos: Pos, size: Direction, color: Vec4.Vec4?): ()
```

Draws a filled rectangle.

`pos` is a corner of the rectangle and `size` goes from that corner to the opposite one. With a positive size,
`pos` is the bottom left corner. A negative size makes the rectangle extend to the left or downward instead.

**Parameters**

- `pos` ([`Pos`](/references/master/graphics/#pos)): The corner of the rectangle. With a positive size, this is the bottom left corner.
- `size` ([`Direction`](/references/master/graphics/#direction)): The width and height of the rectangle.
- `color` (`Vec4.Vec4?`): The fill color. Defaults to black.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A red square centered on the screen.
	graphics.drawRect(vec.V2(-0.05, -0.05), vec.V2(0.1, 0.1), vec4.RED)
end
```

#### See also

- [`ImageResource:draw`](/references/master/image/#imageresourcedraw): draws an image in a rectangle.
- [`graphics.drawCircle`](/references/master/graphics/#graphicsdrawcircle): draws a filled circle.

### graphics.drawPolygon

```luau showLineNumbers=false
graphics.drawPolygon(points: { Pos }, color: Vec4.Vec4?): ()
```

Draws a filled convex polygon.

The points are joined in the order given. The polygon is filled as a fan starting at the first point, so it only
looks right for convex shapes. Nothing is drawn if there are fewer than `3` points.

**Parameters**

- `points` (`{ Pos }`): The corners of the polygon, in order.
- `color` (`Vec4.Vec4?`): The fill color. Defaults to black.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A triangle.
	graphics.drawPolygon({ vec.V2(-0.2, -0.2), vec.V2(0.2, -0.2), vec.V2(0, 0.2) }, vec4.GREEN)
end
```

### graphics.drawLine

```luau showLineNumbers=false
graphics.drawLine(p1: Pos, p2: Pos, color: Vec4.Vec4?, thickness: number?): ()
```

Draws a straight line between two points.

The line is a rectangle with square ends. `thickness` is measured in screen units, from the middle of the line to
one edge, so the visible width is twice `thickness`. Nothing visible is drawn if both points are the same.

**Parameters**

- `p1` ([`Pos`](/references/master/graphics/#pos)): The start of the line.
- `p2` ([`Pos`](/references/master/graphics/#pos)): The end of the line.
- `color` (`Vec4.Vec4?`): The color of the line. Defaults to black.
- `thickness` (`number?`): Half the width of the line, in screen units. Defaults to `0.005`.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const coord = require("@vectarine/coord")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A line from the center of the screen to the top right corner.
	graphics.drawLine(coord.CENTER, coord.TOP_RIGHT, vec4.BLACK, 0.01)
end
```

#### See also

- [`graphics.drawArrow`](/references/master/graphics/#graphicsdrawarrow): draws a line with an arrow head.

### graphics.drawArrow

```luau showLineNumbers=false
graphics.drawArrow(pos: Pos, direction: Direction, color: Vec4.Vec4?, size: number?): ()
```

Draws an arrow that starts at a position and points along a direction.

The shaft goes from `pos` to `pos + direction`. The head is drawn after the end of the shaft, so the tip of the
arrow is a little further than `pos + direction`. Use it to show the speed or the heading of an entity. Nothing is
drawn if `direction` has a length of `0`.

**Parameters**

- `pos` ([`Pos`](/references/master/graphics/#pos)): Where the arrow starts.
- `direction` ([`Direction`](/references/master/graphics/#direction)): The vector the arrow follows. Its length is the length of the shaft.
- `color` (`Vec4.Vec4?`): The color of the arrow. Defaults to black.
- `size` (`number?`): The width of the shaft, in screen units. The head is twice as large. Defaults to `0.01`.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

local position = vec.V2(0, 0)
local velocity = vec.V2(0.3, 0.1)

function Update(deltaTime: number)
	graphics.drawArrow(position, velocity, vec4.RED)
end
```

### graphics.drawCircle

```luau showLineNumbers=false
graphics.drawCircle(center: Pos, radius: number, color: Vec4.Vec4?): ()
```

Draws a filled circle.

The radius is relative to the height of the screen, and the circle stays round whatever the shape of the window.
A radius of `1` reaches the top and bottom edges of the screen.

**Parameters**

- `center` ([`Pos`](/references/master/graphics/#pos)): The center of the circle.
- `radius` (`number`): The radius, in screen units.
- `color` (`Vec4.Vec4?`): The fill color. Defaults to black.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	graphics.drawCircle(vec.V2(0.5, 0.5), 0.1, vec4.ORANGE)
end
```

#### See also

- [`graphics.drawEllipse`](/references/master/graphics/#graphicsdrawellipse): draws an ellipse with two radii.
- [`graphics.drawRect`](/references/master/graphics/#graphicsdrawrect): draws a filled rectangle.

### graphics.drawEllipse

```luau showLineNumbers=false
graphics.drawEllipse(center: Pos, size: Direction, color: Vec4.Vec4?): ()
```

Draws a filled ellipse.

`size` holds the two radii of the ellipse, so the ellipse fits in the rectangle that is `size * 2` wide and tall,
centered on `center`. Unlike [`graphics.drawCircle`](/references/master/graphics/#graphicsdrawcircle), the radii are not corrected for the shape of the window.

**Parameters**

- `center` ([`Pos`](/references/master/graphics/#pos)): The center of the ellipse.
- `size` ([`Direction`](/references/master/graphics/#direction)): The horizontal and vertical radii.
- `color` (`Vec4.Vec4?`): The fill color. Defaults to black.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A wide, flat ellipse, useful as a shadow under a character.
	graphics.drawEllipse(vec.V2(0, -0.3), vec.V2(0.15, 0.04), vec4.DARK_GRAY)
end
```

### graphics.drawWithMask

```luau showLineNumbers=false
graphics.drawWithMask(drawFunction: () -> (), maskFunction: () -> ()): ()
```

Runs `drawFunction` so that it only appears where `maskFunction` drew.

`maskFunction` runs first. Its drawing is not visible and its colors do not matter, only the places it covered.
Then `drawFunction` runs and is cut to those places. Use it to crop an image or a scene to a shape, like a circle.

Everything drawn before the call is flushed first, which has a small cost. Avoid calling it many times per frame.

**Parameters**

- `drawFunction` (`() -> ()`): The drawing to crop.
- `maskFunction` (`() -> ()`): The drawing that defines the visible area.

#### Errors

Errors raised inside either function are raised again by [`graphics.drawWithMask`](/references/master/graphics/#graphicsdrawwithmask).

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	graphics.drawWithMask(function()
		graphics.drawRect(vec.V2(-1, -1), vec.V2(2, 2), vec4.RED)
	end, function()
		graphics.drawCircle(vec.V2(0, 0), 0.4, vec4.WHITE)
	end)
end
```

### graphics.drawSplashScreen

```luau showLineNumbers=false
graphics.drawSplashScreen(loadingText: string?, progress: number?): ()
```

Shows a splash screen over the whole screen.

It clears the screen to black, then draws the Vectarine logo and a progress bar. Use it to show a loading animation
while the game is loading. You can configure the splash screen using the `loading_animation` field in the `.vecta`
manifest. Call [`graphics.drawSplashScreenIfNeeded`](/references/master/graphics/#graphicsdrawsplashscreenifneeded) instead if you only need to wait for resources.

**Parameters**

- `loadingText` (`string?`): A text shown under the logo. Defaults to no text.
- `progress` (`number?`): How full the progress bar is, between `0` and `1`. Values outside this range are clamped. If it is `nil`, the bar shows a moving animation instead.

#### Example

```luau
const graphics = require("@vectarine/graphics")

function Update(deltaTime: number)
	graphics.drawSplashScreen("Generating the world...", 0.5)
end
```

### graphics.drawSplashScreenIfNeeded

```luau showLineNumbers=false
graphics.drawSplashScreenIfNeeded(
	resourcesToWaitFor: { Resource.Resource },
	loadingText: string?,
): boolean
```

Shows the splash screen if any of the resources is not ready yet.

The progress bar shows how many of the resources are ready. A value that is not a resource counts as not ready. With
an empty list, it returns `false` and draws nothing. Return from `Update` when it returns `true`, so that your game
code does not use resources that are not loaded.

**Parameters**

- `resourcesToWaitFor` (`{ Resource.Resource }`): The resources to wait for, such as images or sounds from the [`loader`](/references/master/loader/) module.
- `loadingText` (`string?`): A text shown under the logo. Defaults to no text.

**Returns** True if the splash screen was drawn (some resources are not ready), `false` if everything is ready.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const loader = require("@vectarine/loader")
const vec = require("@vectarine/vec")

const ballImage = loader.loadImage("textures/ball.png")
const jumpSound = loader.loadAudio("audio/jump.wav")

function Update(deltaTime: number)
	if graphics.drawSplashScreenIfNeeded({ ballImage, jumpSound }, "Starting...") then
		return
	end
	ballImage:draw(vec.V2(0, 0), vec.V2(0.2, 0.2))
end
```

#### See also

- [`graphics.drawSplashScreen`](/references/master/graphics/#graphicsdrawsplashscreen): shows the splash screen with a progress you choose.
- [`Resource:isReady`](/references/master/resource/#resourceisready): tells if one resource is ready.

### graphics.withTransformation

```luau showLineNumbers=false
graphics.withTransformation(
	transformation: { translation: Vec.Vec2?, scale: Vec.Vec2?, rotation: number? },
	drawFunction: () -> (),
): ()
```

Runs `drawFunction` with a translation, a scale and a rotation applied to everything it draws.

Use it to move, scale or rotate a group of drawings without changing their code. The transformation is
applied in this order: translation, then scale, then rotation around the origin `(0, 0)`. The translation is in the
local space, so it is also scaled and rotated. Nested calls combine their transformations, and the previous
transformation is restored when `drawFunction` returns. The transformation only applies to 2D drawing functions.

It is used internally to implement the UI system.

**Parameters**

- `transformation` (`{ translation: Vec.Vec2?, scale: Vec.Vec2?, rotation: number? }`): A table with optional fields: `translation` (a [`Vec2`](/references/master/vec/#vec2), defaults to no translation), `scale` (a [`Vec2`](/references/master/vec/#vec2), defaults to `V2(1, 1)`) and `rotation` (an angle in radians, defaults to `0`).
- `drawFunction` (`() -> ()`): The function to run with the transformation applied.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- The square is drawn rotated by 45 degrees and twice as big.
	graphics.withTransformation({ scale = vec.V2(2, 2), rotation = math.pi / 4 }, function()
		graphics.drawRect(vec.V2(-0.05, -0.05), vec.V2(0.1, 0.1), vec4.BLUE)
	end)
end
```

#### See also

- [`graphics.withoutTransformation`](/references/master/graphics/#graphicswithouttransformation): resets the transformation.
- [`Camera2:screen`](/references/master/camera/#camera2screen): converts a world position with a camera.

### graphics.withoutTransformation

```luau showLineNumbers=false
graphics.withoutTransformation(drawFunction: () -> ()): ()
```

Runs `drawFunction` without any transformation.

Inside `drawFunction`, the transformation is reset to the default. You can still call [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation)
there. The previous transformation is restored when `drawFunction` returns. Use it to draw something fixed on the
screen, like a score, inside a transformed scene.

**Parameters**

- `drawFunction` (`() -> ()`): The function to run with no transformation.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	graphics.withTransformation({ scale = vec.V2(0.5, 0.5) }, function()
		graphics.withoutTransformation(function()
			-- Drawn at full size, as if there was no transformation.
			graphics.drawRect(vec.V2(-0.9, 0.8), vec.V2(0.2, 0.1), vec4.RED)
		end)
	end)
end
```

### graphics.transform

```luau showLineNumbers=false
graphics.transform(pos: Vec.Vec2): Vec.Vec2
```

Applies the current transformation of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation) to a position.

Outside of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation), the position is returned unchanged.

**Parameters**

- `pos` ([`Vec.Vec2`](/references/master/vec/#vec2)): A position in the local space.

**Returns** The same position, in screen coordinates.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")

graphics.withTransformation({ translation = vec.V2(0.5, 0) }, function()
	local onScreen = graphics.transform(vec.V2(0, 0))
	print(onScreen.x) -- 0.5
end)
```

### graphics.inverseTransform

```luau showLineNumbers=false
graphics.inverseTransform(pos: Vec.Vec2): Vec.Vec2
```

Applies the inverse of the current transformation of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation) to a position.

Use it to turn a screen position, such as the mouse position, into a position in the transformed space. If the
transformation cannot be inverted (for example a scale of `0`), it returns `V2(0, 0)`.

**Parameters**

- `pos` ([`Vec.Vec2`](/references/master/vec/#vec2)): A position in screen coordinates.

**Returns** The same position, in the local space.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")

graphics.withTransformation({ scale = vec.V2(2, 2) }, function()
	local local_ = graphics.inverseTransform(vec.V2(1, 1))
	print(local_.x) -- 0.5
end)
```

### graphics.getCurrentTransform

```luau showLineNumbers=false
graphics.getCurrentTransform(): (Vec.Vec2, Vec.Vec2, number)
```

Returns the translation, scale and rotation of the current transformation.

With nested calls of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation), it returns the combined transformation. Outside of any
transformation, it returns `V2(0, 0)`, `V2(1, 1)` and `0`.

**Returns** The rotation, as an angle in radians.

#### Example

```luau
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")

graphics.withTransformation({ scale = vec.V2(2, 3), rotation = 0.5 }, function()
	local translation, scale, rotation = graphics.getCurrentTransform()
	print(scale.x, scale.y, rotation) -- 2 3 0.5
end)
```
