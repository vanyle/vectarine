```luau showLineNumbers=false
const loader = require("@vectarine/loader")
```

Loads the external files of your game: images, audio, fonts, texts, shaders, tilesets, tilemaps and scripts.

Each `load*` function returns a resource right away and reads the file in the background, so the game never freezes
while loading. A resource that is not ready yet does nothing when used. Check it with [`Resource:isReady`](/references/master/resource/#resourceisready), or read
[`Resource:getStatus`](/references/master/resource/#resourcegetstatus) to find out why it failed. Loading a file that does not exist does not raise an error: the status
of the resource becomes an error message.

A path is written from the folder of your game (the folder of the `game.vecta` file), like `"images/hero.png"`. A path
that starts with `./` is relative to the script that calls the function instead. Paths must be lowercase, so that the
game works on every platform.

See the [`resource`](/references/master/resource/) module for what you can do with a resource, and the [`image`](/references/master/image/), [`audio`](/references/master/audio/) and [`text`](/references/master/text/) modules for using the
loaded data.

### Example

```luau
const loader = require("@vectarine/loader")
const vec = require("@vectarine/vec")

local hero = loader.loadImage("images/hero.png")
function Update(deltaTime: number)
	if hero:isReady() then
		hero:draw(vec.V2(-0.1, -0.1), vec.V2(0.2, 0.2))
	end
end
```

### Common mistakes

- Calling a `load*` function inside `Update`. Loading the same path again returns the same resource, but it still does
  extra work every frame. Load once at the top of the script.
- Using a resource as soon as it is loaded. It is not ready for a few frames, see [`Resource:isReady`](/references/master/resource/#resourceisready).
- Using an uppercase letter in a path, like `"Images/Hero.png"`. The resource is rejected because paths must be
  lowercase.

## Functions

### loader.loadScript

```luau showLineNumbers=false
loader.loadScript<T>(path: string, type_hint: T?): (Res.ScriptResource, T)
```

Starts loading a Luau script in the background and returns it with the table it exports.

It works like `require`, but it does not wait for the script: it returns immediately with an empty table, and the
script is loaded and run later. Once the script has run, that same table is filled with what the script returns, and
it is updated again when the script is hot-reloaded. Use [`Resource:isReady`](/references/master/resource/#resourceisready) on the returned resource to know when the
table is filled. If the script was already requested before, the table of its exports is returned directly.

Usually, use `require`. Use [`loader.loadScript`](/references/master/loader/#loaderloadscript) when you have a lot of scripts and want to load them in the
background.

The second argument only helps the type checker: pass `require("other.luau")` to get the right type for the
returned module. It has no effect at runtime.

**Parameters**

- `path` (`string`): The path of the script, for example `"scripts/other.luau"`.
- `type_hint` (`T?`): A table used only for typing the returned module. Defaults to `nil`.

**Returns** A pair: the [`ScriptResource`](/references/master/resource/#scriptresource), and the table returned by the script, which is empty until the script is loaded.

#### Example

```luau
const loader = require("@vectarine/loader")

-- The second argument gives the type of the module "other".
local res, other = loader.loadScript("scripts/other.luau", require("other.luau"))
print(res:isReady())
```

### loader.loadImage

```luau showLineNumbers=false
loader.loadImage(path: string, antialiasing: boolean?): Image.ImageResource
```

Starts loading an image and returns it.

The image can be drawn once [`Resource:isReady`](/references/master/resource/#resourceisready) is `true`. Use [`ImageResource:draw`](/references/master/image/#imageresourcedraw) to draw it.

**Parameters**

- `path` (`string`): The path of the image file, for example `"images/hero.png"`.
- `antialiasing` (`boolean?`): True to draw the image with linear filtering (smooth), `false` for nearest filtering (sharp pixels). Defaults to `nil`, which lets the engine choose. For pixel art, pass `false`.

**Returns** The [`ImageResource`](/references/master/image/#imageresource), not ready yet.

#### Example

```luau
const loader = require("@vectarine/loader")
const vec = require("@vectarine/vec")

local tree = loader.loadImage("images/tree.png", false)
function Update(deltaTime: number)
	tree:draw(vec.V2(0, 0), vec.V2(0.3, 0.3))
end
```

#### See also

- [`ImageResource:draw`](/references/master/image/#imageresourcedraw): to draw the image once it is ready.
- [`Resource:isReady`](/references/master/resource/#resourceisready): to know when it is ready.

### loader.loadText

```luau showLineNumbers=false
loader.loadText(path: string): Res.TextResource
```

Starts loading a text file and returns it.

Read its content with [`TextResource:getText`](/references/master/resource/#textresourcegettext) once it is ready. Use it for dialogs, levels or data files.

**Parameters**

- `path` (`string`): The path of the text file, for example `"texts/intro.txt"`.

**Returns** The [`TextResource`](/references/master/resource/#textresource), not ready yet.

#### Example

```luau
const loader = require("@vectarine/loader")

local intro = loader.loadText("texts/intro.txt")
function Update(deltaTime: number)
	if intro:isReady() then
		print(intro:getText())
	end
end
```

#### See also

- [`TextResource:getText`](/references/master/resource/#textresourcegettext): to read the content.

### loader.init

```luau showLineNumbers=false
loader.init(): nil
```

Returns a table that stays the same when the script is hot-reloaded.

Store the functions and values of your script in this table, so that state survives a reload while you edit the
script. The first time the script is loaded, the table is empty. After a reload of the same script, it is the same
table, with the values stored before. The type of the return value is `nil` so that `loader.init() or {}` is typed
as a table by the type checker.

**Returns** The table of the current script. It is never `nil` at runtime.

#### Example

```luau
local loader = require("@vectarine/loader")
local module = loader.init() or {}
if not module.hasBeenLoaded then
	-- This module has been loaded for the first time!
end
-- Define all the properties of your module here
module.hasBeenLoaded = true
return module
```
