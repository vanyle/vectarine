```luau showLineNumbers=false
const text = require("@vectarine/text")
```

Draws and measures text with a font.

Use [`text.font`](/references/master/text/#textfont) to draw with the built-in font (Roboto), or load your own `.ttf` file with [`loader.loadFont`](/references/master/loader/#loaderloadfont) to get a
[`FontResource`](/references/master/text/#fontresource). Then call [`FontResource:drawText`](/references/master/text/#fontresourcedrawtext) every frame to show text, and [`FontResource:measureText`](/references/master/text/#fontresourcemeasuretext) to know how
much room it takes, for example to center it or to put a box around it. For text inside menus, with wrapping and
alignment, see [`ui.text`](/references/master/ui/#uitext).

Sizes are in screen coordinates, where the whole height of the screen is 2. A size of 0.1 is a line that takes 5% of the
height of the screen. See [`coord`](/references/master/coord/) for the coordinate systems.

### Example

```luau
const text = require("@vectarine/text")
const coord = require("@vectarine/coord")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	text.font:drawText("Score: 120", coord.TOP_LEFT + coord.glVec(0.05, -0.15), 0.1, vec4.WHITE)
end
```

### Common mistakes

- [`FontResource:drawText`](/references/master/text/#fontresourcedrawtext) draws nothing, without any error, while a font from [`loader.loadFont`](/references/master/loader/#loaderloadfont) is not loaded yet.
- The position is the start of the baseline, not the bottom left of the text: letters like `"g"` go below it.
- The size is the height of a line in screen coordinates, not in pixels. Use [`coord.pxVec`](/references/master/coord/#coordpxvec) to write it in pixels.

## FontResource

```luau showLineNumbers=false
export type FontResource = ...
```

A font that can draw text, either the built-in font [`text.font`](/references/master/text/#textfont) or a file loaded with [`loader.loadFont`](/references/master/loader/#loaderloadfont).

It is a resource: you can check [`Resource:isReady`](/references/master/resource/#resourceisready) before using it. Call [`FontResource:drawText`](/references/master/text/#fontresourcedrawtext) to draw with it and
[`FontResource:measureText`](/references/master/text/#fontresourcemeasuretext) to measure text.

### FontResource:drawText

```luau showLineNumbers=false
FontResource:drawText(text: string, pos: Pos, size: Size, color: Vec4.Vec4?): ()
```

Draws a line of text at a position, with a size and a color.

`pos` is where the text starts: the left end of its baseline, which is the line the letters sit on. Letters like
`"g"` or `"y"` go below it. `size` is the height of a line of text, sometimes called the line height: no letter is
taller than this. A number is in screen coordinates, where 2 is the height of the screen. With a [`ScreenVec`](/references/master/coord/#screenvec), only the y
component is used. The width of the text follows from the height and keeps the letters undistorted on any window
shape.

The text is drawn on one line. Line breaks are not handled here. Use [`ui.text`](/references/master/ui/#uitext) for wrapping.

The first time a character that is not a letter, digit or common symbol of the English keyboard is drawn (an
accented letter for example), the font prepares it, which takes a moment. If the font is not loaded yet, nothing is
drawn.

**Parameters**

- `text` (`string`): The text to draw.
- `pos` ([`Pos`](/references/master/text/#pos)): Where to start the text, as a [`ScreenPosition`](/references/master/coord/#screenposition) or a [`Vec2`](/references/master/vec/#vec2) in screen coordinates.
- `size` ([`Size`](/references/master/text/#size)): The height of a line, in screen coordinates, or a [`ScreenVec`](/references/master/coord/#screenvec) whose y component is used.
- `color` (`Vec4.Vec4?`): The color of the text. Defaults to black.

#### Example

```luau
const text = require("@vectarine/text")
const coord = require("@vectarine/coord")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- Red text in the middle of the screen
	text.font:drawText("Game over", coord.CENTER, 0.2, vec4.RED)
	-- Written in pixels: 24 pixels high, starting 20 pixels from the left, with its baseline 40 pixels from the top
	text.font:drawText("Menu", coord.px(20, 40), coord.pxVec(0, -24))
end
```

#### See also

- [`FontResource:measureText`](/references/master/text/#fontresourcemeasuretext): measure text before drawing it.
- [`ui.text`](/references/master/ui/#uitext): text with wrapping and alignment inside a UI.

### FontResource:measureText

```luau showLineNumbers=false
FontResource:measureText(
	text: string,
	size: Size,
): { width: number, height: number, bearingY: number }
```

Measures how much space a line of text takes when drawn.

All values are in screen coordinates, where 2 is the height of the screen, and use the same `size` as
[`FontResource:drawText`](/references/master/text/#fontresourcedrawtext). Use it to center text or to draw a background behind it.

The returned table has three fields:

- `width`: the horizontal space of the text.
- `height`: the height of the tallest letter, which is at most `size`.
- `bearingY`: the distance from the baseline to the top of the tallest letter, which is at most `height`.

If the font is not loaded yet, all three values are 0.

Characters that the font has not prepared yet count as 0 wide. The English letters, digits and common symbols are
always ready, but an accented letter only counts once it has been drawn with [`FontResource:drawText`](/references/master/text/#fontresourcedrawtext).

**Parameters**

- `text` (`string`): The text to measure.
- `size` ([`Size`](/references/master/text/#size)): The height of a line, in screen coordinates, or a [`ScreenVec`](/references/master/coord/#screenvec) whose y component is used.

**Returns** A table with the `width`, `height` and `bearingY` of the text.

#### Example

```luau
const text = require("@vectarine/text")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	local size = text.font:measureText("Hello", 0.2)
	-- Draw the text so that its middle is at the center of the screen
	text.font:drawText("Hello", vec.V2(-size.width / 2, 0), 0.2, vec4.WHITE)
end
```

#### See also

- [`FontResource:drawText`](/references/master/text/#fontresourcedrawtext): draw the text.

## Constants

### text.font

```luau showLineNumbers=false
text.font = ...
```

The default font (Roboto), which you can use to draw without loading a `.ttf` file.

It is not a real resource: it is always loaded and is available from the first frame.
