Keeps values across hot-reloads and across game restarts.

Use [`persist.save`](/references/master/persist/#persistsave) and [`persist.load`](/references/master/persist/#persistload) for data the player expects to find again, like a high score or settings.
Use [`persist.onReload`](/references/master/persist/#persistonreload) and [`persist.onReloadWithProvider`](/references/master/persist/#persistonreloadwithprovider) while developing, to keep the state of your game when you edit
a script and the editor reloads it. See the [`loader`](/references/master/loader/) module for another way to keep script state across reloads.

### Example

```luau
const persist = require("@vectarine/persist")

local best = persist.load("best_score") or 0
persist.save("best_score", best + 1)
```

### Common mistakes

- Reading a value right after [`persist.save`](/references/master/persist/#persistsave). Saving can take some time, so the new value may not be there yet.
- Saving something that is not plain data, like a function, a [`Vec2`](/references/master/vec/#vec2) or a resource. Values go through JSON, so
  [`persist.save`](/references/master/persist/#persistsave) raises an error for such a value. Save the numbers inside instead, for example `{ x = v.x, y = v.y }`.
- Calling [`persist.save`](/references/master/persist/#persistsave) every frame. Save at meaningful moments, like the end of a level.
- Using [`persist.onReload`](/references/master/persist/#persistonreload) to keep data between restarts. It only survives hot-reloads. Use [`persist.save`](/references/master/persist/#persistsave).

## Functions

### persist.onReload

```luau showLineNumbers=false
persist.onReload<T>(defaultValue: T, globalName: string): T
```

Returns a value that survives hot-reloads, creating it from a default value the first time.

The value is stored in a global variable named `globalName`, so it can be inspected in the watcher. The first time
this function is called, the global is set to `defaultValue` and `defaultValue` is returned. After a hot-reload, the
global already holds a value, and that value is returned instead of `defaultValue`. Changes to the value itself are
kept only if it is a table: assigning a new number or string to your local variable does not update the global.

If `defaultValue` is expensive to create, use [`persist.onReloadWithProvider`](/references/master/persist/#persistonreloadwithprovider).

**Parameters**

- `defaultValue` (`T`): The value to use when there is no value yet.
- `globalName` (`string`): The name of the global variable that holds the value. Use a different name for each value.

**Returns** The stored value, or `defaultValue` the first time.

#### Example

```luau
const persist = require("@vectarine/persist")

local state = persist.onReload({ score = 0 }, "gameState")
function Update(deltaTime: number)
	state.score += deltaTime
end
```

#### See also

- [`persist.onReloadWithProvider`](/references/master/persist/#persistonreloadwithprovider): when the default value is expensive to create.
- [`loader.init`](/references/master/loader/#loaderinit): to keep a whole script table.

### persist.onReloadWithProvider

```luau showLineNumbers=false
persist.onReloadWithProvider<T>(provider: () -> T, globalName: string): T
```

Returns a value that survives hot-reloads, creating it with a function the first time.

It works like [`persist.onReload`](/references/master/persist/#persistonreload), but `provider` is called only when there is no stored value yet. Use it when the
default value is expensive to create, so that it is not rebuilt on every hot-reload.

**Parameters**

- `provider` (`() -> T`): A function that returns the initial value. It is not called after a hot-reload.
- `globalName` (`string`): The name of the global variable that holds the value. Use a different name for each value.

**Returns** The stored value, or the value returned by `provider` the first time.

#### Errors

Raises an error if `provider` raises one.

#### Example

```luau
const persist = require("@vectarine/persist")

local grid = persist.onReloadWithProvider(function()
	local cells = {}
	for i = 1, 10000 do
		cells[i] = 0
	end
	return cells
end, "gridCells")
```

### persist.save

```luau showLineNumbers=false
persist.save(name: string, value: any)
```

Saves a value so that it is still there after the game restarts.

The value is stored under `name` and read back with [`persist.load`](/references/master/persist/#persistload). Saving again with the same name replaces the
previous value. The value is converted to JSON, so use numbers, strings, booleans and tables of those. Functions and
other objects, like vectors and resources, cannot be saved.

Saving can take some time, so calling [`persist.save`](/references/master/persist/#persistsave) followed by [`persist.load`](/references/master/persist/#persistload) might not give the expected result.
Don't call it every frame.

**Parameters**

- `name` (`string`): The name of the saved value. Use only letters, numbers, underscores and dots.
- `value` (`any`): The value to save.

#### Errors

Raises an error if the value, or something inside it, cannot be converted to JSON. Nothing is saved in that case,
and the previous value saved under `name` is kept.

#### Example

```luau
const persist = require("@vectarine/persist")

persist.save("settings", { volume = 0.8, fullscreen = false })
```

#### See also

- [`persist.load`](/references/master/persist/#persistload): to read the value back.

### persist.load

```luau showLineNumbers=false
persist.load(name: string): any?
```

Loads a value saved with [`persist.save`](/references/master/persist/#persistsave).

**Parameters**

- `name` (`string`): The name used when saving.

**Returns** The saved value, or `nil` if nothing was saved under this name.

#### Errors

Raises an error if the saved data cannot be read back, for example if the file was edited by hand.

#### Example

```luau
const persist = require("@vectarine/persist")

local settings = persist.load("settings")
local volume = if settings then settings.volume else 1
print(volume)
```

#### See also

- [`persist.save`](/references/master/persist/#persistsave): to save a value.
