Provides 4D vectors, used mostly to represent colors and rotations.

A [`Vec4`](/references/master/vec4/#vec4) has four numbers: `x`, `y`, `z` and `w`. The same numbers are also available as `r`, `g`, `b` and `a`,
which is how colors are stored: red, green, blue and alpha (opacity), each between 0 and 1. Functions that draw
things, like the ones of [`graphics`](/references/master/graphics/), take colors as [`Vec4`](/references/master/vec4/#vec4). This module defines the common colors, like [`vec4.RED`](/references/master/vec4/#vec4red).

[`Vec4`](/references/master/vec4/#vec4) can also be used as a quaternion to rotate things in 3D (see [`vec4.fromRotation`](/references/master/vec4/#vec4fromrotation) and [`Vec4:qmul`](/references/master/vec4/#vec4qmul)), or as a
plain 4D vector. For 2D positions and sizes, use [`vec`](/references/master/vec/) instead.

### Example

```luau
const vec4 = require("@vectarine/vec4")

local sky = vec4.createColor(0.2, 0.4, 0.9, 1)
local dusk = sky:lerp(vec4.ORANGE, 0.5)
print(dusk:round(2)) -- V4(0.6, 0.45, 0.45, 1)
```

### Common mistakes

- Colors go from 0 to 1, not from 0 to 255: divide by 255 if you start from values like `(200, 120, 40)`.
- Vectors from constants like [`vec4.RED`](/references/master/vec4/#vec4red) cannot be modified. Create a copy with [`vec4.createColor`](/references/master/vec4/#vec4createcolor) to change one.
- `*` multiplies component by component. To scale a whole vector by a number, use [`Vec4:scale`](/references/master/vec4/#vec4scale).

## Functions

### vec4.V4

```luau showLineNumbers=false
vec4.V4(x: number, y: number, z: number, w: number): Vec4
```

Creates a 4D vector from its four components.

Use [`vec4.createColor`](/references/master/vec4/#vec4createcolor) instead when the vector is a color, as it reads better.

**Parameters**

- `x` (`number`): The first component. It is also available as `r`.
- `y` (`number`): The second component. It is also available as `g`.
- `z` (`number`): The third component. It is also available as `b`.
- `w` (`number`): The fourth component. It is also available as `a`.

**Returns** A new vector.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local v = vec4.V4(1, 2, 3, 4)
print(v.x, v.w) -- 1	4
v.y = 10
print(v.g) -- 10
```

### vec4.fromRotation

```luau showLineNumbers=false
vec4.fromRotation(axis: Vec4, angle: number): Vec4
```

Creates a quaternion representing a rotation of `angle` radians around an axis.

Only the `x`, `y` and `z` components of `axis` are used, the `w` component is ignored. The axis should have a length
of 1 (see [`Vec4:normalized`](/references/master/vec4/#vec4normalized)): the result has a length of 1 only in that case. The result stores the rotation as
`(cos(angle / 2), axis.x * sin(angle / 2), axis.y * sin(angle / 2), axis.z * sin(angle / 2))`, so its `x`
component is the scalar part. Combine rotations with [`Vec4:qmul`](/references/master/vec4/#vec4qmul).

**Parameters**

- `axis` ([`Vec4`](/references/master/vec4/#vec4)): The direction of the axis of rotation. Only `x`, `y` and `z` are read.
- `angle` (`number`): The rotation angle in radians.

**Returns** A new quaternion.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local quarterTurn = vec4.fromRotation(vec4.V4(0, 0, 1, 0), math.pi / 2)
print(quarterTurn:length()) -- 1
```

### vec4.createColor

```luau showLineNumbers=false
vec4.createColor(r: number, g: number, b: number, a: number): Vec4
```

Creates a color from its red, green, blue and alpha components.

This does the same as [`vec4.V4`](/references/master/vec4/#vec4v4). Components are numbers between 0 and 1, where `a` is the opacity: 0 is fully
transparent and 1 is fully opaque. Values outside that range are not clamped by this function.

**Parameters**

- `r` (`number`): The amount of red, from 0 to 1.
- `g` (`number`): The amount of green, from 0 to 1.
- `b` (`number`): The amount of blue, from 0 to 1.
- `a` (`number`): The opacity, from 0 (transparent) to 1 (opaque).

**Returns** A new color.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local seaGreen = vec4.createColor(0.1, 0.6, 0.4, 1)
print(seaGreen.g) -- 0.6
```

#### See also

- [`vec4.V4`](/references/master/vec4/#vec4v4): the same function, for vectors that are not colors.
- [`Vec4:lerp`](/references/master/vec4/#vec4lerp): fades between two colors.

## Vec4

```luau showLineNumbers=false
export type Vec4 = ...
```

A vector of four numbers, used for colors and rotations.

You get one from a constructor like [`vec4.V4`](/references/master/vec4/#vec4v4) or [`vec4.createColor`](/references/master/vec4/#vec4createcolor), from a constant like [`vec4.RED`](/references/master/vec4/#vec4red), or as the
result of a method such as [`Vec4:lerp`](/references/master/vec4/#vec4lerp). You can add (`+`), subtract (`-`) and negate (`-v`) vectors. Multiplying
(`*`) and dividing (`/`) two vectors works component by component. To multiply by a number, use [`Vec4:scale`](/references/master/vec4/#vec4scale).

The vectors stored in constants like [`vec4.RED`](/references/master/vec4/#vec4red) cannot be modified.

**Operators**

`a + b` — `(a: Vec4, b: Vec4): Vec4`

Adds two vectors component by component: `a + b`.

`a - b` — `(a: Vec4, b: Vec4): Vec4`

Subtracts two vectors component by component: `a - b`.

`-a` — `(a: Vec4): Vec4`

Negates every component of the vector: `-a`.

`a * b` — `(a: Vec4, b: Vec4): Vec4`

Multiplies two vectors component by component: `a * b`. This is not a dot product, see [`Vec4:dot`](/references/master/vec4/#vec4dot).

`a / b` — `(a: Vec4, b: Vec4): Vec4`

Divides two vectors component by component: `a / b`. Dividing by a zero component gives `inf` or `nan`.

### Vec4:scale

```luau showLineNumbers=false
Vec4:scale(k: number): Vec4
```

Multiplies every component of the vector by a number.

**Parameters**

- `k` (`number`): The factor. A negative value flips the vector, 0 gives the zero vector.

**Returns** A new vector. The original is not modified.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local v = vec4.V4(1, 2, 3, 4):scale(0.5)
print(v.x, v.w) -- 0.5	2
```

### Vec4:qmul

```luau showLineNumbers=false
Vec4:qmul(b: Vec4): Vec4
```

Multiplies two quaternions, treating both vectors as quaternions.

Quaternions store a rotation. Multiplying two of them gives the rotation that applies `b`, then `a`. The `x`
component is the scalar part and `y`, `z`, `w` are the vector part, the same layout as [`vec4.fromRotation`](/references/master/vec4/#vec4fromrotation).
The order matters: `a:qmul(b)` is in general not equal to `b:qmul(a)`.

**Parameters**

- `b` ([`Vec4`](/references/master/vec4/#vec4)): The second quaternion.

**Returns** A new quaternion. It is not normalized: its length is the product of both lengths.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local axis = vec4.V4(0, 0, 1, 0)
local quarter = vec4.fromRotation(axis, math.pi / 2)
local half = quarter:qmul(quarter)
print(half:round(3).w) -- 1
```

### Vec4:dot

```luau showLineNumbers=false
Vec4:dot(b: Vec4): number
```

Returns the dot product of two vectors.

This is `a.x * b.x + a.y * b.y + a.z * b.z + a.w * b.w`.

**Parameters**

- `b` ([`Vec4`](/references/master/vec4/#vec4)): The other vector.

**Returns** The dot product.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

print(vec4.V4(1, 2, 3, 4):dot(vec4.V4(1, 0, 1, 0))) -- 4
```

### Vec4:length

```luau showLineNumbers=false
Vec4:length(): number
```

Returns the length of the vector.

The length is `math.sqrt(v.x*v.x + v.y*v.y + v.z*v.z + v.w*v.w)`. If you only compare lengths, [`Vec4:lengthSq`](/references/master/vec4/#vec4lengthsq)
is faster because it skips the square root.

**Returns** The length, always 0 or more.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

print(vec4.V4(2, 0, 0, 0):length()) -- 2
```

### Vec4:lengthSq

```luau showLineNumbers=false
Vec4:lengthSq(): number
```

Returns the square of the length of the vector.

This is `v.x*v.x + v.y*v.y + v.z*v.z + v.w*v.w`. It avoids a square root, so it is cheaper than [`Vec4:length`](/references/master/vec4/#vec4length).

**Returns** The squared length, always 0 or more.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

print(vec4.V4(1, 2, 2, 0):lengthSq()) -- 9
```

### Vec4:normalized

```luau showLineNumbers=false
Vec4:normalized(): Vec4
```

Returns the vector scaled to a length of 1.

The direction is kept. The zero vector cannot be scaled, so it is returned as the zero vector.

**Returns** A new vector of length 1, or the zero vector if the length is 0.

#### Example

```luau

print(axis.z) -- 1
```

### Vec4:round

```luau showLineNumbers=false
Vec4:round(digits_of_precision: number?): Vec4
```

Returns the vector with each component rounded to a number of decimal digits.

Halves are rounded away from zero. It is useful to print vectors or to remove tiny floating point errors.

**Parameters**

- `digits_of_precision` (`number?`): The number of digits to keep after the decimal point. Defaults to 0, which rounds to the nearest integer. It cannot be negative.

**Returns** A new vector.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local v = vec4.V4(0.123456, 1.5, -2.5, 0)
print(v:round()) -- V4(0, 2, -3, 0)
print(v:round(2)) -- V4(0.12, 1.5, -2.5, 0)
```

#### Errors

Raises an error if `digits_of_precision` is negative.

**Parameters**


### Vec4:lerp

```luau showLineNumbers=false
Vec4:lerp(b: Vec4, k: number): Vec4
```

Returns a vector linearly interpolated between two vectors.

The result is `a + (b - a) * k`. With colors, it fades from one color to another. The factor is not clamped: a
value outside 0 to 1 goes past `a` or `b`.

**Parameters**

- `b` ([`Vec4`](/references/master/vec4/#vec4)): The vector reached when `k` is 1.
- `k` (`number`): The interpolation factor. 0 gives `a`, 1 gives `b`, 0.5 gives the middle.

**Returns** A new vector.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local fade = vec4.BLACK:lerp(vec4.WHITE, 0.25)
print(fade.r) -- 0.25
```

#### See also

- [`vec4.createColor`](/references/master/vec4/#vec4createcolor): creates a color.

### Vec4:noise

```luau showLineNumbers=false
Vec4:noise(): number
```

Returns the simplex noise value at the position given by the vector.

Noise is a smooth pseudo-random function: close points give close values. It is useful for terrain, clouds or
natural-looking movement. The four components are the four coordinates of the point, and the seed is fixed, so the
same point always gives the same value. Uses [simplex noise](https://en.wikipedia.org/wiki/OpenSimplex_noise).

**Returns** The noise value at that point.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local time = 0
function Update(deltaTime: number)
	time += deltaTime
	local wobble = vec4.V4(time, 0, 0, 0):noise()
	print(wobble)
end
```

### Vec4:worleyNoise

```luau showLineNumbers=false
Vec4:worleyNoise(): number
```

Returns the Worley noise value at the position given by the vector.

Worley noise is based on the distance to random points, which gives a cell-like pattern. The four components are
the four coordinates of the point, and the seed is fixed, so the same point always gives the same value. Uses
[Worley noise](https://en.wikipedia.org/wiki/Worley_noise). See [`Vec4:noise`](/references/master/vec4/#vec4noise) for a smoother alternative.

**Returns** The noise value at that point.

#### Example

```luau
const vec4 = require("@vectarine/vec4")

local cell = vec4.V4(1.5, 2.5, 0, 0):worleyNoise()
print(cell)
```
