Fast lists of 2D vectors, for processing and drawing thousands of objects at once.

A [`FastList`](/references/master/fastlist/#fastlist) is a list of [`Vec2`](/references/master/vec/#vec2) stored in a compact way. Where a plain table of [`Vec2`](/references/master/vec/#vec2) needs a Lua loop to change or
draw every element, a fastlist applies one operation to all its elements in a single call to native code. Use one
when you have many similar objects, such as particles, bullets, tiles or stars. For a few objects, a plain table of
[`Vec2`](/references/master/vec/#vec2) is simpler and fast enough.

Most [`Vec2`](/references/master/vec/#vec2) operations exist on fastlists with the same name: [`FastList:scale`](/references/master/fastlist/#fastlistscale), [`FastList:normalized`](/references/master/fastlist/#fastlistnormalized), `+`, `-`...
They work element by element and return a new fastlist. A fastlist can also be combined with a single [`Vec2`](/references/master/vec/#vec2), which
is then used for every element. The functions starting with `draw`, such as [`FastList:drawRects`](/references/master/fastlist/#fastlistdrawrects) and
[`FastList:drawImages`](/references/master/fastlist/#fastlistdrawimages), draw many shapes in one call. Functions of this module create fastlists, for example
[`fastlist.fromTable`](/references/master/fastlist/#fastlistfromtable) from a table of vectors. Read elements back with [`FastList:get`](/references/master/fastlist/#fastlistget) or [`FastList:toTable`](/references/master/fastlist/#fastlisttotable).

Indices start at 1, like in Lua tables. When a fastlist is combined with another fastlist of a different length,
the result has the length of the shorter one.

A gap is an empty slot, like a `nil` in a table. Filtering functions such as [`FastList:filterBetweenX`](/references/master/fastlist/#fastlistfilterbetweenx) replace the
elements they reject with [`fastlist.GAP`](/references/master/fastlist/#fastlistgap), so that every element keeps its index. Gaps are removed with
[`FastList:replaceGaps`](/references/master/fastlist/#fastlistreplacegaps) or [`FastList:filterGaps`](/references/master/fastlist/#fastlistfiltergaps). See [`fastlist.GAP`](/references/master/fastlist/#fastlistgap).

See [`vec`](/references/master/vec/) for the vectors stored in a fastlist.

### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local positions = fastlist.fromTable({ vec.V2(0, 0), vec.V2(0.5, 0.5) })
local velocities = fastlist.fromValue(vec.V2(0.5, 0), 2)
local moved = positions + velocities:scale(0.5)
print(moved:get(2)) -- V2(0.75, 0.5)
```

### Common mistakes

- A fastlist passed as an argument to a method whose description says it "consumes" it cannot be used afterwards.
If you still need that list, create it again, for example with [`fastlist.fromTable`](/references/master/fastlist/#fastlistfromtable).
- A gap is not `nil`: `list:get(i)` returns a vector full of `nan` for it, and `list:get(i).x == 0` is `false`. Test with
[`FastList:countGaps`](/references/master/fastlist/#fastlistcountgaps) or remove gaps with [`FastList:filterGaps`](/references/master/fastlist/#fastlistfiltergaps) before using the values.
- Some methods turn gaps into regular vectors. When a method does not keep gaps, its description says so.
- `list * 2` raises an error, because operators need a fastlist or a [`Vec2`](/references/master/vec/#vec2). Use [`FastList:scale`](/references/master/fastlist/#fastlistscale) to multiply by a
number.

## Functions

### fastlist.newLinspace

```luau showLineNumbers=false
fastlist.newLinspace(min: Vec.Vec2, max: Vec.Vec2, step: Vec.Vec2): FastList
```

Creates a fastlist of the points of a regular grid.

The points go from `min` to `max` (included, when a point lands exactly on it) with a distance of `step` between
two points. They are ordered row by row: `x` changes first, then `y`. The distance is added again and again, so
tiny rounding errors can accumulate on long lists.

**Parameters**

- `min` ([`Vec.Vec2`](/references/master/vec/#vec2)): The first point of the grid, which is its bottom left corner.
- `max` ([`Vec.Vec2`](/references/master/vec/#vec2)): The opposite corner of the grid. No point goes past it.
- `step` ([`Vec.Vec2`](/references/master/vec/#vec2)): The distance between two points, on each axis. Both components must be greater than 0.

**Returns** A new fastlist.

#### Errors

Raises an error if a component of `step` is 0 or negative.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local grid = fastlist.newLinspace(vec.V2(0, 0), vec.V2(2, 1), vec.V2(1, 1))
print(#grid) -- 6
print(grid:get(2)) -- V2(1, 0)
print(grid:get(4)) -- V2(0, 1)
```

#### See also

- [`fastlist.fromTable`](/references/master/fastlist/#fastlistfromtable): build a list from your own points.

## FastList

```luau showLineNumbers=false
export type FastList = ...
```

A list of [`Vec2`](/references/master/vec/#vec2) stored in a compact way, which can be processed and drawn all at once.

You get one from a constructor of the [`fastlist`](/references/master/fastlist/) module such as [`fastlist.fromTable`](/references/master/fastlist/#fastlistfromtable), or as the result of a
method of this type. Methods return a new list and leave the original unchanged, unless their description says
they change it in place. Use `#list` for the number of elements and [`FastList:get`](/references/master/fastlist/#fastlistget) to read one element. Methods
whose name starts with `draw` display the list.

Some methods consume a fastlist argument: after `a:concat(b)`, `b` can no longer be used. The description of
such a method says "consumes".

**Operators**

`#a` — `(self: FastList): number`

Returns the number of elements of the fastlist.

You usually write `#fastlist`, which calls this function. Gaps count as elements.


#### Example

```luau
const fastlist = require("@vectarine/fastlist")

local list = fastlist.zeros(8)
print(#list) -- 8
```

`a + b` — `(self: FastList, other: FastListOrVec): FastList`

Returns the element-wise sum of the fastlist and another fastlist or a vector.

With a fastlist, elements at the same index are added, and the result has the length of the shorter list. With a
vector, it is added to every element. The fastlist must be on the left of the `+`.


#### Errors

Raises an error if `other` is neither a fastlist nor a vector.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local positions = fastlist.fromValue(vec.V2(0, 0), 3)
local moved = positions + vec.V2(0.5, 0.25)
print(moved:get(3)) -- V2(0.5, 0.25)
```

`a - b` — `(self: FastList, other: FastListOrVec): FastList`

Returns the element-wise difference of the fastlist and another fastlist or a vector.

It follows the same rules as `+`.


#### Errors

Raises an error if `other` is neither a fastlist nor a vector.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local positions = fastlist.fromValue(vec.V2(1, 1), 2)
print((positions - vec.V2(0.5, 0.5)):get(1)) -- V2(0.5, 0.5)
```

`-a` — `(self: FastList): FastList`

Returns a fastlist where both components of every element are negated.

`a * b` — `(self: FastList, other: FastListOrVec): FastList`

Returns the element-wise product of the fastlist and another fastlist or a vector.

It follows the same rules as `+`. Components are multiplied one by one. To multiply every element by a number,
use [`FastList:scale`](/references/master/fastlist/#fastlistscale).


#### Errors

Raises an error if `other` is neither a fastlist nor a vector.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local sizes = fastlist.fromValue(vec.V2(2, 4), 2)
print((sizes * vec.V2(0.5, 0.25)):get(1)) -- V2(1, 1)
```

`a / b` — `(self: FastList, other: FastListOrVec): FastList`

Returns the element-wise quotient of the fastlist and another fastlist or a vector.

It follows the same rules as `+`. A zero component in the divisor gives `inf` or `nan`, and a `nan` in both
components is a gap.


#### Errors

Raises an error if `other` is neither a fastlist nor a vector.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local sizes = fastlist.fromValue(vec.V2(2, 4), 2)
print((sizes / vec.V2(2, 2)):get(1)) -- V2(1, 2)
```

### FastList:get


### FastList:forEach

```luau showLineNumbers=false
FastList:forEach(fn: (Vec.Vec2, number) -> Vec.Vec2): ()
```

Replaces every element of the fastlist by the result of a function, changing the list in place.

The function is called for each element, in order, with a copy of the vector and its index (starting at 1). It must
return a vector, which becomes the new element. Changing the vector received by the function has no effect unless
it is returned. If the function raises an error, the loop stops and the elements already visited keep their new
value.

This method calls Lua code once per element, so it is much slower than the other methods. Use it only when
nothing else can express what you need.

**Parameters**

- `fn` (`(Vec.Vec2, number) -> Vec.Vec2`): The function called with the vector and its index. It must return the new vector.

#### Errors

Raises an error if `fn` does not return a vector.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local list = fastlist.zeros(3)
list:forEach(function(v, i)
	return vec.V2(i, i * 2)
end)
print(list:get(3)) -- V2(3, 6)
```

#### See also

- [`FastList:scale`](/references/master/fastlist/#fastlistscale): faster operations on all elements.

### FastList:weave

```luau showLineNumbers=false
FastList:weave(others: { FastList }): FastList
```

Returns a new fastlist that alternates the elements of several fastlists.

If the fastlists are ABC, DEF and GHI, the result is ADGBEHCFI: the first element of each list, then the second
element of each list, and so on. The list `self` comes first in each round, then the lists of `others` in order.
This is how you build the groups of vectors that the `draw` methods expect, such as a position followed by a size.
When the lists have different lengths, a list that has run out is skipped. If `others` is empty, the result is a
copy of `self`. This method consumes the lists in `others`: they cannot be used after this call.

**Parameters**

- `others` (`{ FastList }`): The fastlists to weave with `self`.

**Returns** A new fastlist. Its length is the sum of the lengths of all the lists.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local positions = fastlist.fromTable({ vec.V2(0, 0), vec.V2(0.5, 0) })
local sizes = fastlist.fromValue(vec.V2(0.1, 0.1), 2)
local pairs = positions:weave({ sizes })
print(#pairs) -- 4
print(pairs:get(2)) -- V2(0.1, 0.1)
```

#### See also

- [`FastList:unweave`](/references/master/fastlist/#fastlistunweave): the opposite operation.
- [`FastList:drawImages`](/references/master/fastlist/#fastlistdrawimages): uses position and size pairs.

### FastList:unweave

```luau showLineNumbers=false
FastList:unweave(groupCount: number): { FastList }
```

Splits a fastlist into several fastlists by dealing its elements in turn. This is the opposite of
[`FastList:weave`](/references/master/fastlist/#fastlistweave).

A fastlist like ADGBEHCFI with a group count of 3 becomes ABC, DEF and GHI. ADGBEH with a group count of 2 becomes
AGE and DBH. If the length of the list is not a multiple of `groupCount`, the first groups are one element longer
than the others.

**Parameters**

- `groupCount` (`number`): The number of fastlists to produce. It must be at least 1.

**Returns** A table of `groupCount` fastlists.

#### Errors

Raises an error if `groupCount` is 0.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local mixed = fastlist.fromTable({ vec.V2(1, 0), vec.V2(2, 0), vec.V2(3, 0), vec.V2(4, 0) })
local groups = mixed:unweave(2)
print(table.concat(groups[1]:toNumberTableX(), ", ")) -- 1, 3
print(table.concat(groups[2]:toNumberTableX(), ", ")) -- 2, 4
```

#### See also

- [`FastList:weave`](/references/master/fastlist/#fastlistweave): the opposite operation.

### FastList:filterBetweenX

```luau showLineNumbers=false
FastList:filterBetweenX(
	mask: FastList,
	min: number | FastList,
	max: number | FastList,
): FastList
```

Replaces the elements of the fastlist with gaps, except where the `x` component of the mask is between `min` and `max`.

The element at index `i` is kept if `min < mask[i].x < max`, which excludes both limits. Otherwise it becomes
[`fastlist.GAP`](/references/master/fastlist/#fastlistgap). An existing gap in the fastlist stays a gap, and a gap in the mask always gives a gap. The result has
the length of the shortest of [`fastlist`](/references/master/fastlist/), `mask` and, when they are lists, `min` and `max`.

In a plain table, this is a loop that keeps `list[i]` when `min < mask[i].x and mask[i].x < max`. Here, one call does it for the whole list.

Use `math.huge` for `max` or `-math.huge` for `min` to leave one side open. When `min` or `max` is a fastlist, the
`x` component of its element at the same index is the limit for that element.

**Parameters**

- `mask` ([`FastList`](/references/master/fastlist/#fastlist)): The list whose `x` components are tested.
- `min` (`number | FastList`): The lower limit, as a number or as a fastlist with one limit per element.
- `max` (`number | FastList`): The upper limit, as a number or as a fastlist with one limit per element.

**Returns** A new fastlist where the rejected elements are gaps.

#### Errors

Raises an error if `mask` is not a fastlist, or if `min` or `max` is neither a number nor a fastlist.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local ages = fastlist.fromTable({ vec.V2(1, 0), vec.V2(5, 0), vec.V2(9, 0) })
local enemies = fastlist.fromTable({ vec.V2(0, 0), vec.V2(0.5, 0), vec.V2(1, 0) })
local alive = enemies:filterBetweenX(ages, -math.huge, 6)
print(alive:countGaps()) -- 1
```

#### See also

- [`FastList:filterBetweenY`](/references/master/fastlist/#fastlistfilterbetweeny): filter on the y component.
- [`FastList:replaceGaps`](/references/master/fastlist/#fastlistreplacegaps): fill the gaps.

### FastList:filterBetweenY

```luau showLineNumbers=false
FastList:filterBetweenY(
```

Replaces the elements of the fastlist with gaps, except where the `y` component of the mask is between `min`
and `max`.

It works like [`FastList:filterBetweenX`](/references/master/fastlist/#fastlistfilterbetweenx), but tests the `y` component of the mask and, when `min` or `max` is a

**Parameters**

- `min` (`number | FastList`): The lower limit, as a number or as a fastlist with one limit per element.
- `max` (`number | FastList`): The upper limit, as a number or as a fastlist with one limit per element.

**Returns** A new fastlist where the rejected elements are gaps.

#### Errors

Raises an error if `mask` is not a fastlist, or if `min` or `max` is neither a number nor a fastlist.

#### Example

```luau
const vec = require("@vectarine/vec")
const fastlist = require("@vectarine/fastlist")

local stars = fastlist.fromTable({ vec.V2(0, -0.5), vec.V2(0, 0.5), vec.V2(0, 2) })
```

### FastList:filterGaps

## Constants

### fastlist.GAP

```luau showLineNumbers=false
fastlist.GAP = ...
```

The value of an empty slot in a fastlist, similar to a `nil` in a table.

A gap is a [`Vec2`](/references/master/vec/#vec2) whose two components are `nan` (not a number). Filtering a fastlist with
[`FastList:filterBetweenX`](/references/master/fastlist/#fastlistfilterbetweenx) or [`FastList:filterBetweenY`](/references/master/fastlist/#fastlistfilterbetweeny) gives a new fastlist where the rejected elements are gaps.
Gaps are contagious: adding, subtracting, multiplying or dividing a gap gives a gap. Remove them with
[`FastList:replaceGaps`](/references/master/fastlist/#fastlistreplacegaps) or [`FastList:filterGaps`](/references/master/fastlist/#fastlistfiltergaps). Some methods do not keep gaps: their description says so.
