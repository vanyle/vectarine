Creates canvases, which are images you draw on, and the shaders that can change how a canvas looks when it is drawn.

A canvas is a surface that you paint on with the functions of [`graphics`](/references/master/graphics/), [`text`](/references/master/text/) and the other drawing modules, instead
of painting on the screen. Once painted, you draw the canvas like an image, which lets you reuse a complex drawing, draw
it scaled or in several places, or apply an effect to it. A shader is a small GPU program loaded with [`loader.loadShader`](/references/master/loader/#loaderloadshader)
that receives the canvas as a texture and decides the color of each pixel, for example for blur, outlines or color
changes. See [`graphics`](/references/master/graphics/) for the drawing functions and [`Canvas:paint`](/references/master/canvas/#canvaspaint) to paint on a canvas.

### Example

```luau
const canvas = require("@vectarine/canvas")
const graphics = require("@vectarine/graphics")
const coord = require("@vectarine/coord")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

local minimap = canvas.createCanvas(128, 128)

function Update(deltaTime: number)
	minimap:paint(function()
		graphics.clear(vec4.BLACK)
		graphics.drawCircle(vec.V2(0, 0), 0.1, vec4.RED)
	end)
	minimap:draw(vec.V2(0.5, 0.5), vec.V2(0.4, 0.4))
end
```

### Common mistakes

- Creating a canvas is expensive. Do not call [`canvas.createCanvas`](/references/master/canvas/#canvascreatecanvas) every frame: create it once and reuse it.
- [`Canvas:paint`](/references/master/canvas/#canvaspaint) does not clear the canvas, so drawings pile up from one frame to the next. Call [`graphics.clear`](/references/master/graphics/#graphicsclear)
  first.
- A shader that is not loaded yet draws nothing, and [`Canvas:setUniform`](/references/master/canvas/#canvassetuniform) is ignored until it is ready.

## Functions

### canvas.createCanvas

```luau showLineNumbers=false
canvas.createCanvas(width: number, height: number): Canvas
```

Creates an empty canvas of a given size in pixels.

The canvas starts fully transparent. Its size cannot change afterwards: create a new canvas if you need another
size. Its pixels are smoothed when it is drawn smaller or larger.

Creating a canvas is expensive. Create canvases once, when the game starts, and reuse them. Do not create one every
frame.

**Parameters**

- `width` (`number`): The width of the canvas in pixels. It must be a whole number.
- `height` (`number`): The height of the canvas in pixels. It must be a whole number.

**Returns** The new [`Canvas`](/references/master/canvas/#canvas).

#### Errors

Raises an error if `width` or `height` cannot be converted to a non-negative whole number, for example a negative
number.

#### Example

```luau
const canvas = require("@vectarine/canvas")

-- Created once, outside of Update
local buffer = canvas.createCanvas(256, 144)
print(buffer:getSize()) -- 256, 144
```

#### See also

- [`Canvas:paint`](/references/master/canvas/#canvaspaint): draw on the canvas.
- [`Canvas:draw`](/references/master/canvas/#canvasdraw): draw the canvas on the screen.

A shader that can be applied to a canvas.

## Canvas

```luau showLineNumbers=false
export type Canvas = ...
```

A drawing surface that you paint on and then draw like an image.

You get one from [`canvas.createCanvas`](/references/master/canvas/#canvascreatecanvas). Paint on it with [`Canvas:paint`](/references/master/canvas/#canvaspaint), draw it with [`Canvas:draw`](/references/master/canvas/#canvasdraw) or
[`Canvas:drawPart`](/references/master/canvas/#canvasdrawpart), and optionally change how it looks with [`Canvas:setShader`](/references/master/canvas/#canvassetshader). A canvas has a fixed size in pixels.

### Canvas:paint

```luau showLineNumbers=false
Canvas:paint(draw_function: () -> ()): ()
```

Runs a function whose drawing goes to the canvas instead of the screen.

All drawing functions called by `draw_function` (those of [`graphics`](/references/master/graphics/), [`text`](/references/master/text/), images, and also [`Canvas:draw`](/references/master/canvas/#canvasdraw) of
another canvas) draw on this canvas until the function returns. You can call `paint` inside another `paint`: the
innermost canvas receives the drawing while its function runs.

The canvas uses screen coordinates, like the screen: (-1, -1) is its bottom left, (0, 0) its center and (1, 1) its
top right, whatever its size in pixels. Pixel positions made with [`coord.px`](/references/master/coord/#coordpx) are computed from the size of the
window, not of the canvas, unless you pass the canvas size to them.

Painting does not clear the canvas: what was drawn before stays, and new drawings are added on top. Call
[`graphics.clear`](/references/master/graphics/#graphicsclear) at the start of the function to repaint it from scratch.

Once painted, draw the canvas with [`Canvas:draw`](/references/master/canvas/#canvasdraw) or [`Canvas:drawPart`](/references/master/canvas/#canvasdrawpart). If you paint the same content every frame,
consider painting only when it changes.

**Parameters**

- `draw_function` (`() -> ()`): The function that does the drawing. It receives no argument.

#### Errors

If `draw_function` raises an error, the error is raised again by `paint`, after the drawing it already did has been
sent to the canvas.

#### Example

```luau
const canvas = require("@vectarine/canvas")
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

local sprite = canvas.createCanvas(64, 64)

function Update(deltaTime: number)
	sprite:paint(function()
		graphics.clear(vec4.TRANSPARENT)
		graphics.drawRect(vec.V2(-0.5, -0.5), vec.V2(1, 1), vec4.GREEN)
	end)
end
```

#### See also

- [`Canvas:draw`](/references/master/canvas/#canvasdraw): draw the painted canvas.
- [`graphics.clear`](/references/master/graphics/#graphicsclear): start from an empty canvas.

### Canvas:setShader

```luau showLineNumbers=false
Canvas:setShader(shader: ShaderResource?): ()
```

Sets the shader used to draw this canvas, or removes it.

When the canvas is drawn with [`Canvas:draw`](/references/master/canvas/#canvasdraw) or [`Canvas:drawPart`](/references/master/canvas/#canvasdrawpart), it is not copied as is. Instead, the shader
receives the canvas as a texture and its output is what appears on screen. Use it for post-processing effects,
outlines, recoloring and so on. The shader sees the canvas as a texture named `tex` and the time in seconds since
the game started as a float named `iTime`, in the style of [ShaderToy](https://www.shadertoy.com/), where you can
find many examples.

Pass `nil` to go back to drawing the canvas as is. The shader only affects drawing: painting on the canvas is not
changed.

If the shader is not loaded yet, or failed to load or compile, nothing is drawn when the canvas is drawn. Wait for
[`Resource:isReady`](/references/master/resource/#resourceisready) if you do not want the canvas to disappear for a few frames.

**Parameters**

- `shader` (`ShaderResource?`): The shader to use, from [`loader.loadShader`](/references/master/loader/#loaderloadshader), or `nil` to remove the shader.

#### Example

```luau
const canvas = require("@vectarine/canvas")
const loader = require("@vectarine/loader")
const vec = require("@vectarine/vec")

local scene = canvas.createCanvas(320, 180)
local blur = loader.loadShader("shaders/blur.glsl")
scene:setShader(blur)

function Update(deltaTime: number)
	scene:draw(vec.V2(-1, -1), vec.V2(2, 2))
end
```

#### See also

- [`loader.loadShader`](/references/master/loader/#loaderloadshader): load a shader.
- [`Canvas:setUniform`](/references/master/canvas/#canvassetuniform): send values to the shader.

### Canvas:setUniform

```luau showLineNumbers=false
Canvas:setUniform(name: string, value: number | vec.Vec2 | vec4.Vec4): ()
```

Sets a uniform of the shader of this canvas, a value that the shader can read.

Use it to send values from your game to the shader, for example the strength of an effect. `name` is the name of
the uniform in the shader code. A number is sent as a float, a [`Vec2`](/references/master/vec/#vec2) as a `vec2` and a [`Vec4`](/references/master/vec4/#vec4) as a [`vec4`](/references/master/vec4/). Whole
numbers are also sent as floats.

The value is set on the shader itself, so canvases that use the same shader share it.

If the canvas has no shader, or the shader is not loaded or compiled yet, the call does nothing and the value is
lost. Call it again once the shader is ready.

If the shader has no uniform with this name (for example because it never uses it and the compiler removed it), a
warning is printed in the console and nothing else happens.

**Parameters**

- `name` (`string`): The name of the uniform in the shader.
- `value` (`number | vec.Vec2 | vec4.Vec4`): The value to set: a number, a [`Vec2`](/references/master/vec/#vec2) or a [`Vec4`](/references/master/vec4/#vec4).

#### Errors

Raises an error if `value` is of another type, for example a string. This is only checked once the shader is ready.

#### Example

```luau
const canvas = require("@vectarine/canvas")
const loader = require("@vectarine/loader")
const vec = require("@vectarine/vec")

local scene = canvas.createCanvas(320, 180)
local wave = loader.loadShader("shaders/wave.glsl")
scene:setShader(wave)

function Update(deltaTime: number)
	scene:setUniform("amplitude", 0.05)
	scene:draw(vec.V2(-1, -1), vec.V2(2, 2))
end
```

### Canvas:getSize

```luau showLineNumbers=false
Canvas:getSize(): vec.Vec2
```

Returns the size of the canvas in pixels.

This is the size given to [`canvas.createCanvas`](/references/master/canvas/#canvascreatecanvas). It is a size in pixels, not in screen coordinates.

**Returns** The width in `x` and the height in `y`.

#### Example

```luau
const canvas = require("@vectarine/canvas")

local buffer = canvas.createCanvas(200, 100)
local size = buffer:getSize()
print(size.x / size.y) -- 2
```

### Canvas:draw

```luau showLineNumbers=false
Canvas:draw(pos: Pos, size: Direction): ()
```

Draws the canvas at a position, stretched to a size.

`pos` is the bottom left corner of the canvas and `size` goes right and up from there. Both are in screen
coordinates, where the screen is 2 wide and 2 high. The canvas is stretched to `size` whatever its size in pixels,
so keep its proportions in mind if you do not want it to look squashed.

If the canvas has a shader (see [`Canvas:setShader`](/references/master/canvas/#canvassetshader)), the shader decides how it is drawn. The current transformation
of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation) applies.

**Parameters**

- `pos` ([`Pos`](/references/master/canvas/#pos)): The position of the bottom left corner of the canvas.
- `size` ([`Direction`](/references/master/canvas/#direction)): The size to draw it at. Positive values go right and up.

#### Example

```luau
const canvas = require("@vectarine/canvas")
const vec = require("@vectarine/vec")

local buffer = canvas.createCanvas(128, 128)

function Update(deltaTime: number)
	-- A square in the top right quarter of the screen
	buffer:draw(vec.V2(0, 0), vec.V2(1, 1))
end
```

#### See also

- [`Canvas:drawPart`](/references/master/canvas/#canvasdrawpart): draw only a region of the canvas.
- [`Canvas:setShader`](/references/master/canvas/#canvassetshader): change how the canvas looks.

### Canvas:drawPart

```luau showLineNumbers=false
Canvas:drawPart(
	dest_p1: Pos,
	dest_p2: Pos,
	dest_p3: Pos,
	dest_p4: Pos,
	src_pos: vec.Vec2,
	src_size: vec.Vec2,
): ()
```

Draws a part of the canvas, stretched to fit a quadrilateral given by 4 corners.

Use it to draw only a region of a canvas, or to draw it as a rotated or skewed shape. The destination corners are
in screen coordinates, and must be given in this order: bottom left, bottom right, top right, top left. The source
region is given as fractions of the canvas rather than pixels: `src_pos` is its bottom left corner and `src_size`
its size, where (0, 0) is the bottom left of the canvas and (1, 1) its top right. So `(vec.V2(0, 0), vec.V2(1, 1))`
is the whole canvas, which is what [`Canvas:draw`](/references/master/canvas/#canvasdraw) uses.

Unlike [`ImageResource:drawPart`](/references/master/image/#imageresourcedrawpart), where `src_pos` is the top left corner of the part and y goes down, here (0, 0) is
the bottom left corner of the canvas and y goes up, like everywhere else on screen.

If the canvas has a shader (see [`Canvas:setShader`](/references/master/canvas/#canvassetshader)), the shader decides how it is drawn. The current transformation
of [`graphics.withTransformation`](/references/master/graphics/#graphicswithtransformation) applies.

**Parameters**

- `dest_p1` ([`Pos`](/references/master/canvas/#pos)): The destination of the bottom left corner of the region.
- `dest_p2` ([`Pos`](/references/master/canvas/#pos)): The destination of the bottom right corner of the region.
- `dest_p3` ([`Pos`](/references/master/canvas/#pos)): The destination of the top right corner of the region.
- `dest_p4` ([`Pos`](/references/master/canvas/#pos)): The destination of the top left corner of the region.
- `src_pos` ([`vec.Vec2`](/references/master/vec/#vec2)): The bottom left corner of the region to draw, as fractions from 0 to 1 of the size of the canvas.
- `src_size` ([`vec.Vec2`](/references/master/vec/#vec2)): The size of the region to draw, as fractions from 0 to 1 of the size of the canvas.

#### Example

```luau
const canvas = require("@vectarine/canvas")
const vec = require("@vectarine/vec")

local atlas = canvas.createCanvas(256, 256)

function Update(deltaTime: number)
	-- Draw the top right quarter of the canvas over the whole screen
	atlas:drawPart(
		vec.V2(-1, -1), vec.V2(1, -1), vec.V2(1, 1), vec.V2(-1, 1),
		vec.V2(0.5, 0.5), vec.V2(0.5, 0.5)
	)
end
```
