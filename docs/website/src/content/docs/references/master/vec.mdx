2D vectors, used for positions, sizes, directions and speeds.

A [`Vec2`](/references/master/vec/#vec2) holds two numbers, `x` and `y`. Create one with [`vec.V2`](/references/master/vec/#vecv2), or with [`vec.fromAngle`](/references/master/vec/#vecfromangle) when you know a direction.
Combine vectors with `+`, `-`, `*` and `/` (all component by component), and use methods such as [`Vec2:scale`](/references/master/vec/#vec2scale),
[`Vec2:length`](/references/master/vec/#vec2length) and [`Vec2:distance`](/references/master/vec/#vec2distance) to move things around and measure them. Because 2D vectors are so common
(your screen is 2D!), this module is called [`vec`](/references/master/vec/) instead of `vec2`.

When you need to process thousands of vectors at once, see [`fastlist`](/references/master/fastlist/). See [`vec4`](/references/master/vec4/) for 4D vectors and colors.

### Example

```luau
const vec = require("@vectarine/vec")

local position = vec.V2(0, 0)
local velocity = vec.V2(0.5, 0.25)
local target = position + velocity:scale(0.5)
print(target) -- V2(0.25, 0.125)
```

### Common mistakes

- Vectors are shared, not copied: after `local b = a`, `b.x = 1` also changes `a`. Build a new vector with
[`vec.V2(a.x, a.y)`](/references/master/vec/#vecv2) or `a:scale(1)` to get an independent copy.
- `v * 2` raises an error, because `*` needs two vectors. Use [`Vec2:scale`](/references/master/vec/#vec2scale) to multiply by a number. The same goes for
`+`, `-` and `/`.
- Methods described as "in place", such as [`Vec2:add`](/references/master/vec/#vec2add), change the vector they are called on.
Constants such as [`vec.ZERO2`](/references/master/vec/#veczero2) cannot be changed, so create a copy with [`vec.V2`](/references/master/vec/#vecv2) before modifying one.

## Functions

### vec.V2

```luau showLineNumbers=false
vec.V2(x: number, y: number): Vec2
```

Creates a 2D vector from its `x` and `y` components.

On the screen, `x` goes to the right and `y` goes up, and (-1, -1) is the bottom left corner while (1, 1) is
the top right corner.

**Parameters**

- `x` (`number`): The horizontal component.
- `y` (`number`): The vertical component.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local position = vec.V2(0.5, -0.25)
print(position.x) -- 0.5
print(position.y) -- -0.25
```

#### See also

- [`vec.fromAngle`](/references/master/vec/#vecfromangle): build a vector from a direction.
- [`Vec2:length`](/references/master/vec/#vec2length): measure a vector.

### vec.fromAngle

```luau showLineNumbers=false
vec.fromAngle(angle: number, length: number?): Vec2
```

Creates a vector of a given length that points in the direction of an angle.

The angle is in radians and is measured from the positive `x` axis. Positive angles turn counterclockwise on the
screen. This is the same as [`vec.V2(math.cos(angle), math.sin(angle)) * vec.V2(length, length)`](/references/master/vec/#vecv2).

**Parameters**

- `angle` (`number`): The direction, in radians. 0 points right and `math.pi / 2` points up.
- `length` (`number?`): The length of the vector. Defaults to 1.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local right = vec.fromAngle(0, 2)
print(right) -- V2(2, 0)
local shot = vec.fromAngle(math.rad(45), 0.5)
print(shot.x > 0 and shot.y > 0) -- true
```

#### See also

- [`Vec2:angle`](/references/master/vec/#vec2angle): get the angle of a vector.
- [`Vec2:cmul`](/references/master/vec/#vec2cmul): rotate a vector.

## Vec2

```luau showLineNumbers=false
export type Vec2 = ...
```

A 2D vector with an `x` and a `y` component.

You get one from [`vec.V2`](/references/master/vec/#vecv2) or [`vec.fromAngle`](/references/master/vec/#vecfromangle), or as the result of a method such as [`Vec2:scale`](/references/master/vec/#vec2scale). Use it for
positions, sizes and directions, and pass it to drawing functions. Change its components with `v.x = 1`, or
with the methods described as "in place", such as [`Vec2:add`](/references/master/vec/#vec2add). Vectors are objects: after `local b = a`, both names refer to the
same vector, so changing one changes the other. Operators and most methods return a new vector instead of
changing the original.

**Operators**

`a + b` — `(a: Vec2, b: Vec2): Vec2`

Returns the component-wise sum `a + b` as a new vector. Both operands must be vectors, not numbers.

`a - b` — `(a: Vec2, b: Vec2): Vec2`

Returns the component-wise difference `a - b` as a new vector. Both operands must be vectors, not numbers.

`-a` — `(a: Vec2): Vec2`

Returns the opposite `-a` of the vector, with both components negated.

`a * b` — `(a: Vec2, b: Vec2): Vec2`

Returns the component-wise product `a * b` as a new vector. To multiply by a number, use [`Vec2:scale`](/references/master/vec/#vec2scale).

`a / b` — `(a: Vec2, b: Vec2): Vec2`

Returns the component-wise quotient `a / b` as a new vector. A zero component in `b` gives `inf` or `nan`.

### Vec2:scale

```luau showLineNumbers=false
Vec2:scale(k: number): Vec2
```

Returns the vector multiplied by a number.

Both components are multiplied by `k`. The original vector is not changed. Use [`Vec2:rescale`](/references/master/vec/#vec2rescale) to change it in
place.

**Parameters**

- `k` (`number`): The factor. A negative value flips the direction of the vector.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local velocity = vec.V2(1, 2)
local slower = velocity:scale(0.5)
print(slower) -- V2(0.5, 1)
```

#### See also

- [`Vec2:rescale`](/references/master/vec/#vec2rescale): scale in place.
- [`Vec2:normalized`](/references/master/vec/#vec2normalized): get a vector of length 1.

### Vec2:cmul

```luau showLineNumbers=false
Vec2:cmul(b: Vec2): Vec2
```

Returns the product of two vectors seen as complex numbers.

The vector `(x, y)` stands for the complex number `x + y i`, so that
`(a.x + i a.y) * (b.x + i b.y) = (a.x*b.x - a.y*b.y) + i(a.x*b.y + a.y*b.x)`.
Multiplying by a vector of length 1 rotates `a` by the angle of `b` without changing its length.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The vector to multiply by.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local a = vec.V2(1, 2)
local b = vec.V2(3, 4)
print(a:cmul(b)) -- V2(-5, 10)
```

### Vec2:dot

```luau showLineNumbers=false
Vec2:dot(b: Vec2): number
```

Returns the dot product of the two vectors.

The dot product is `a.x*b.x + a.y*b.y`. It is positive when the vectors point roughly the same way, zero when
they are perpendicular and negative when they point in opposite ways. For vectors of length 1, it is the cosine of
the angle between them.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The other vector.

**Returns** The dot product, as a number.

#### Example

```luau
const vec = require("@vectarine/vec")

local forward = vec.V2(1, 0)
local toEnemy = vec.V2(0.5, 0.5):normalized()
print(forward:dot(toEnemy) > 0) -- true, the enemy is in front
```

### Vec2:length

```luau showLineNumbers=false
Vec2:length(): number
```

Returns the length of the vector.

The length is `math.sqrt(v.x*v.x + v.y*v.y)`. If you only need to compare lengths, [`Vec2:lengthSq`](/references/master/vec/#vec2lengthsq) is faster
because it skips the square root.

**Returns** The length, which is never negative.

#### Example

```luau
const vec = require("@vectarine/vec")

local v = vec.V2(3, 4)
print(v:length()) -- 5
```

#### See also

- [`Vec2:lengthSq`](/references/master/vec/#vec2lengthsq): compare lengths faster.
- [`Vec2:distance`](/references/master/vec/#vec2distance): distance between two points.

### Vec2:lengthSq

```luau showLineNumbers=false
Vec2:lengthSq(): number
```

Returns the square of the length of the vector.

The result is `v.x*v.x + v.y*v.y`. It avoids a square root, so it is faster than [`Vec2:length`](/references/master/vec/#vec2length). Use it to compare
distances: `a:lengthSq() < r * r` is the same test as `a:length() < r`.

**Returns** The squared length, which is never negative.

#### Example

```luau
const vec = require("@vectarine/vec")

local offset = vec.V2(3, 4)
print(offset:lengthSq()) -- 25
print(offset:lengthSq() < 2 * 2) -- false
```

#### See also

- [`Vec2:length`](/references/master/vec/#vec2length): the real length.

### Vec2:distance

```luau showLineNumbers=false
Vec2:distance(b: Vec2): number
```

Returns the distance between two points.

This is the same as `(a - b):length()`. Use it with vectors that are positions.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The other point.

**Returns** The distance, which is never negative.

#### Example

```luau
const vec = require("@vectarine/vec")

local player = vec.V2(0, 0)
local coin = vec.V2(3, 4)
print(player:distance(coin)) -- 5
```

#### See also

- [`Vec2:length`](/references/master/vec/#vec2length): length of one vector.

### Vec2:angle

```luau showLineNumbers=false
Vec2:angle(): number
```

Returns the angle of the vector, in radians.

The angle is measured from the positive `x` axis and goes from -`math.pi` to `math.pi`. It is the opposite of
[`vec.fromAngle`](/references/master/vec/#vecfromangle). The zero vector gives 0.

**Returns** The angle, in radians. A vector pointing right gives 0 and a vector pointing up gives `math.pi / 2`.

#### Example

```luau
const vec = require("@vectarine/vec")

print(vec.V2(1, 0):angle()) -- 0
local up = vec.V2(0, 1)
print(math.floor(up:angle() * 100) / 100) -- 1.57
```

#### See also

- [`vec.fromAngle`](/references/master/vec/#vecfromangle): the opposite conversion.

### Vec2:normalized

```luau showLineNumbers=false
Vec2:normalized(): Vec2
```

Returns the vector scaled to a length of 1.

The direction stays the same. This is useful to get a direction from a difference of positions, then scale it to
a speed.

**Returns** A new vector of length 1, or the zero vector if the vector has zero length.

#### Example

```luau
const vec = require("@vectarine/vec")

local toTarget = vec.V2(0, 2)
local step = toTarget:normalized():scale(0.5)
print(step) -- V2(0, 0.5)
print(vec.ZERO2:normalized()) -- V2(0, 0)
```

#### See also

- [`Vec2:length`](/references/master/vec/#vec2length): measure a vector.
- [`Vec2:scale`](/references/master/vec/#vec2scale): change the length.

### Vec2:round

```luau showLineNumbers=false
Vec2:round(digits_of_precision: number?): Vec2
```

Returns the vector with each component rounded to a number of decimal digits.

With 0 digits, components are rounded to the nearest integer. With 2 digits, 0.126 becomes 0.13.

**Parameters**

- `digits_of_precision` (`number?`): The number of digits kept after the decimal point. Defaults to 0.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local v = vec.V2(1.26, 2.5)
print(v:round()) -- V2(1, 3)
print(v:round(1)) -- V2(1.3, 2.5)
```

### Vec2:max

```luau showLineNumbers=false
Vec2:max(b: Vec2): Vec2
```

Returns a vector made of the larger component of each pair.

The result has `math.max(a.x, b.x)` as `x` and `math.max(a.y, b.y)` as `y`.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The other vector.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local a = vec.V2(1, 5)
local b = vec.V2(3, 2)
print(a:max(b)) -- V2(3, 5)
```

#### See also

- [`Vec2:min`](/references/master/vec/#vec2min): the lower bound.

### Vec2:min

```luau showLineNumbers=false
Vec2:min(b: Vec2): Vec2
```

Returns a vector made of the smaller component of each pair.

The result has `math.min(a.x, b.x)` as `x` and `math.min(a.y, b.y)` as `y`. Combined with [`Vec2:max`](/references/master/vec/#vec2max), it keeps a
position inside an area.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The other vector.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local player = vec.V2(1.5, -0.5)
local clamped = player:min(vec.V2(1, 1)):max(vec.V2(-1, -1))
print(clamped) -- V2(1, -0.5)
```

#### See also

- [`Vec2:max`](/references/master/vec/#vec2max): the upper bound.

### Vec2:lerp

```luau showLineNumbers=false
Vec2:lerp(b: Vec2, k: number): Vec2
```

Returns the point between two vectors at a given fraction of the way.

The result is `a + (b - a) * k`. It is often used to move something smoothly toward a target.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The vector reached when `k` is 1.
- `k` (`number`): The fraction of the way from `a` to `b`. 0 gives `a`, 1 gives `b`. The value is not limited to the range 0 to 1: other values go past the ends.

**Returns** A new vector.

#### Example

```luau
const vec = require("@vectarine/vec")

local start = vec.V2(0, 0)
local goal = vec.V2(1, 2)
print(start:lerp(goal, 0.25)) -- V2(0.25, 0.5)
```

#### See also

- [`Vec2:min`](/references/master/vec/#vec2min): limit a position.
- [`Vec2:distance`](/references/master/vec/#vec2distance): distance to the target.

### Vec2:noise

```luau showLineNumbers=false
Vec2:noise(): number
```

Returns the simplex noise value at the point `v`.

Simplex noise is smooth random-looking noise: nearby points give similar values. It is useful for terrain,
clouds or wobbling movements. The noise is the same on every run.
See [simplex noise](https://en.wikipedia.org/wiki/OpenSimplex_noise).

**Returns** The noise value at this point.

#### Example

```luau
const vec = require("@vectarine/vec")

local height = vec.V2(3.2, 1.7):noise()
print(height)
```

### Vec2:worleyNoise

```luau showLineNumbers=false
Vec2:worleyNoise(): number
```

Returns the Worley noise value at the point `v`.

Worley noise is based on the distance to the nearest of many scattered points. It looks like cells or stones.
The noise is the same on every run. See [Worley noise](https://en.wikipedia.org/wiki/Worley_noise).

**Returns** The noise value at this point.

#### Example

```luau
const vec = require("@vectarine/vec")

local cell = vec.V2(3.2, 1.7):worleyNoise()
print(cell)
```

### Vec2:add

```luau showLineNumbers=false
Vec2:add(b: Vec2): Vec2
```

Adds a vector to this one, changing this vector in place.

Unlike `+`, this does not create a new vector, which avoids extra work when done every frame. It returns `a`
itself, so calls can be chained.

**Parameters**

- `b` ([`Vec2`](/references/master/vec/#vec2)): The vector to add.

**Returns** The vector `a`, after the change.

#### Errors

Raises an error if `a` is a constant such as [`vec.ZERO2`](/references/master/vec/#veczero2).

#### Example

```luau
const vec = require("@vectarine/vec")

local position = vec.V2(0, 0)
position:add(vec.V2(0.5, 0.25))
print(position) -- V2(0.5, 0.25)
```

#### See also

- [`Vec2:sub`](/references/master/vec/#vec2sub): subtract in place.
- [`Vec2:rescale`](/references/master/vec/#vec2rescale): multiply by a number in place.

## Constants

### vec.ZERO2

```luau showLineNumbers=false
vec.ZERO2 = ...
```

The zero vector, [`V2(0, 0)`](/references/master/vec/#vecv2). It is a constant: changing it or calling an in-place method such as [`Vec2:add`](/references/master/vec/#vec2add) on it
raises an error.
