Follows the loading of resources, like images, sounds, fonts and texts.

A resource is an external piece of data, stored in a file of your game. You get one by calling a function of the
[`loader`](/references/master/loader/) module, like [`loader.loadImage`](/references/master/loader/#loaderloadimage). Loading is asynchronous: the function returns right away and the file is read
in the background. Use [`Resource:isReady`](/references/master/resource/#resourceisready) or [`Resource:getStatus`](/references/master/resource/#resourcegetstatus) to know when it can be used. You don't need to
require this module: what it describes is available on every resource.

### Example

```luau
const loader = require("@vectarine/loader")

local image = loader.loadImage("images/hero.png")
function Update(deltaTime: number)
	if image:isReady() then
		print("Hero loaded")
	end
end
```

### Common mistakes

- Using a resource right after loading it. It is not ready yet, so drawing or playing it does nothing and a warning is
  printed. Check [`Resource:isReady`](/references/master/resource/#resourceisready) first.
- Never checking the status. If the file is missing, the resource stays unusable and the only hint is the
  `"Error: ..."` text of [`Resource:getStatus`](/references/master/resource/#resourcegetstatus).

## Resource

```luau showLineNumbers=false
export type Resource = ...
```

Any resource returned by a [`loader`](/references/master/loader/) function.

Use it to follow the loading of a file, for example with [`Resource:isReady`](/references/master/resource/#resourceisready).

### Resource:getStatus

```luau showLineNumbers=false
Resource:getStatus(): string | "Not yet loaded" | "Loading" | "Loaded"
```

Returns the loading status of a resource as a string.

When a [`loader`](/references/master/loader/) function is called, the resource starts as not loaded. Once per frame, resources that are not loaded
are scheduled for loading and become `"Loading"`. When loading ends, the status becomes `"Loaded"`, or
`"Error: <description>"` if something went wrong, for example if the file does not exist.

Using a resource that is not `"Loaded"` does nothing and prints a warning in the console.

**Returns** The status: `"Loaded"`, `"Loading"`, `"Error: <description>"`, or `"Not yet loaded"` before loading starts.

#### Example

```luau
const loader = require("@vectarine/loader")

local music = loader.loadAudio("audio/theme.ogg")
function Update(deltaTime: number)
	if music:getStatus() ~= "Loaded" then
		print(music:getStatus())
	end
end
```

- [`Resource:isReady`](/references/master/resource/#resourceisready): a simple `true` or `false` check.
- [`loader`](/references/master/loader/): the functions that create resources.

### Resource:isReady

```luau showLineNumbers=false
Resource:isReady(): boolean
```

Returns `true` if the resource is loaded and can be used.

This is the same as checking that [`Resource:getStatus`](/references/master/resource/#resourcegetstatus) returns `"Loaded"`. It is `false` while the resource is
loading and when loading failed.

**Returns** True if the status is `"Loaded"`.

#### Example

```luau
const loader = require("@vectarine/loader")

local text = loader.loadText("texts/intro.txt")
function Update(deltaTime: number)
	if text:isReady() then
		print(text:getText())
	end
end
```

#### See also

- [`Resource:getStatus`](/references/master/resource/#resourcegetstatus): to see why a resource is not ready.

### Resource:getId

```luau showLineNumbers=false
Resource:getId(): number
```

Returns the identifier of a resource.

The identifier is a number that is unique to the resource. It stays the same when the game is hot-reloaded, but not
when it is restarted.

**Returns** The identifier.

#### Example

```luau
const loader = require("@vectarine/loader")

local image = loader.loadImage("images/hero.png")
print(image:getId())
```

## TextResource

```luau showLineNumbers=false
export type TextResource = ...
```

A text file loaded with [`loader.loadText`](/references/master/loader/#loaderloadtext).

Once it is ready, read its content with [`TextResource:getText`](/references/master/resource/#textresourcegettext).

### TextResource:getText

```luau showLineNumbers=false
TextResource:getText(): string?
```

Returns the content of a text resource.

The file is read as UTF-8 text. Invalid bytes are replaced by the character U+FFFD.

**Returns** The content of the file, or `nil` if the resource is not loaded yet or failed to load.

#### Example

```luau
const loader = require("@vectarine/loader")

local dialog = loader.loadText("texts/dialog.txt")
function Update(deltaTime: number)
	local content = dialog:getText()
	if content then
		print(content)
	end
end
```

#### See also

- [`loader.loadText`](/references/master/loader/#loaderloadtext): to load a text file.
