Creates and converts positions and sizes written in different coordinate systems.

Most drawing functions work in screen coordinates: (-1, -1) is the bottom left of the screen, (1, 1) is the top
right and (0, 0) is the center. The whole screen is 2 wide and 2 high. This is what [`gl`](/references/master/coord/#coordgl) means in function names
like [`coord.gl`](/references/master/coord/#coordgl). Pixels are easier to think about when you place things by hand, so this module lets you write a
position in pixels ([`coord.px`](/references/master/coord/#coordpx)), in screen coordinates ([`coord.gl`](/references/master/coord/#coordgl)), or relative to the width ([`coord.vw`](/references/master/coord/#coordvw)) or the
height ([`coord.vh`](/references/master/coord/#coordvh)) of the screen. Every function returns a [`ScreenPosition`](/references/master/coord/#screenposition) (a point on the screen) or, for the `Vec`
variants, a [`ScreenVec`](/references/master/coord/#screenvec) (a distance on the screen). Both can be passed to the functions of [`graphics`](/references/master/graphics/) and [`text`](/references/master/text/) in
place of a [`Vec2`](/references/master/vec/#vec2), and both can be converted back to a [`Vec2`](/references/master/vec/#vec2) with their [`gl`](/references/master/coord/#coordgl) and [`px`](/references/master/coord/#coordpx) methods, for example [`ScreenPosition:px`](/references/master/coord/#screenpositionpx).

A plain [`Vec2`](/references/master/vec/#vec2) given to a drawing function is read as screen coordinates. Constants such as [`coord.CENTER`](/references/master/coord/#coordcenter) give
ready-made positions for the corners and the center of the screen.

### Example

```luau
const coord = require("@vectarine/coord")
const graphics = require("@vectarine/graphics")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A 100x50 pixels rectangle, 10 pixels away from the top left corner of the window
	graphics.drawRect(coord.px(10, 60), coord.pxVec(100, -50), vec4.RED)
end
```

### Common mistakes

- Pixel functions ([`coord.px`](/references/master/coord/#coordpx), [`coord.pxVec`](/references/master/coord/#coordpxvec), [`ScreenPosition:px`](/references/master/coord/#screenpositionpx)) use the size of the window, not the size of the
  canvas being painted. Pass the canvas size as an extra argument when painting on a [`Canvas`](/references/master/canvas/#canvas).
- In pixels, y goes down (the origin is the top left). In every other system, y goes up. Use a negative y with
  [`coord.pxVec`](/references/master/coord/#coordpxvec) to go up.
- A rectangle is drawn from its bottom left corner, so a position in pixels is the bottom of the rectangle, not its top.

## Functions

### coord.px

```luau showLineNumbers=false
coord.px(
	v_or_x: Vec.Vec2 | number,
	screen_size_px_or_y: number | Vec.Vec2?,
	screen_size_px_or_nil: Vec.Vec2?,
): ScreenPosition
```

Creates a [`ScreenPosition`](/references/master/coord/#screenposition) from a position in pixels.

The origin (0, 0) is the top left of the screen, x goes right and y goes down. The bottom right corner is
(width, height). This is the same convention as HTML5 canvas, Love2D, Processing or Raylib.

You can call it in three ways: [`coord.px(10, 20)`](/references/master/coord/#coordpx), [`coord.px(vec.V2(10, 20))`](/references/master/coord/#coordpx), or with an explicit screen size as
the last argument: [`coord.px(10, 20, size)`](/references/master/coord/#coordpx) or [`coord.px(vec.V2(10, 20), size)`](/references/master/coord/#coordpx).

The conversion needs the size of the screen. By default it uses the size of the window (the same numbers as
[`io.getWindowSize`](/references/master/io/#iogetwindowsize)), even while a canvas is being painted. Pass a size to convert for something else, for example
the size of a canvas.

**Parameters**

- `v_or_x` (`Vec.Vec2 | number`): The position as a [`Vec2`](/references/master/vec/#vec2), or only its x component (in pixels) when the second argument is the y component.
- `screen_size_px_or_y` (`number | Vec.Vec2?`): The y component (in pixels) when the first argument is a number, otherwise the screen size as a [`Vec2`](/references/master/vec/#vec2).
- `screen_size_px_or_nil` (`Vec.Vec2?`): The screen size as a [`Vec2`](/references/master/vec/#vec2), when the first two arguments are numbers.

**Returns** The position as a [`ScreenPosition`](/references/master/coord/#screenposition).

#### Errors

Raises an error (`"Invalid arguments"`) if the first two arguments are neither two numbers nor a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const coord = require("@vectarine/coord")
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A 50x50 pixels square, 20 pixels from the top left corner. A rectangle is drawn from its bottom left
	-- corner, so the position is 50 pixels lower than the top of the square and the size goes up.
	graphics.drawRect(coord.px(20, 70), coord.pxVec(50, -50), vec4.BLUE)
	-- The same, using a Vec2 and a fixed screen size of 320x240
	graphics.drawRect(coord.px(vec.V2(20, 70), vec.V2(320, 240)), coord.pxVec(50, -50, vec.V2(320, 240)), vec4.RED)
end
```

#### See also

- [`coord.pxVec`](/references/master/coord/#coordpxvec): a size or distance in pixels.
- [`coord.vw`](/references/master/coord/#coordvw): positions relative to the screen width.

### coord.pxVec

```luau showLineNumbers=false
coord.pxVec(
	v_or_x: Vec.Vec2 | number,
	screen_size_px_or_y: number | Vec.Vec2?,
	screen_size_px_or_nil: Vec.Vec2?,
): ScreenVec
```

Creates a [`ScreenVec`](/references/master/coord/#screenvec) from a distance in pixels.

A distance has no origin. As in [`coord.px`](/references/master/coord/#coordpx), positive x goes right and positive y goes down, so use a negative y
to go up.

It takes the same arguments as [`coord.px`](/references/master/coord/#coordpx): two numbers, or a [`Vec2`](/references/master/vec/#vec2), optionally followed by a screen size. By
default the size of the window is used, even while a canvas is being painted.

**Parameters**

- `v_or_x` (`Vec.Vec2 | number`): The distance as a [`Vec2`](/references/master/vec/#vec2), or only its x component (in pixels) when the second argument is the y component.
- `screen_size_px_or_y` (`number | Vec.Vec2?`): The y component (in pixels, positive goes down) when the first argument is a number, otherwise the screen size as a [`Vec2`](/references/master/vec/#vec2).
- `screen_size_px_or_nil` (`Vec.Vec2?`): The screen size as a [`Vec2`](/references/master/vec/#vec2), when the first two arguments are numbers.

**Returns** The distance as a [`ScreenVec`](/references/master/coord/#screenvec).

#### Errors

Raises an error (`"Invalid arguments"`) if the first two arguments are neither two numbers nor a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const coord = require("@vectarine/coord")

local size = coord.pxVec(100, 40)
-- In an 800x600 window, 100 pixels are a quarter of the screen width in screen coordinates:
print(size:gl()) -- 0.25, -0.1333
```

### coord.gl

```luau showLineNumbers=false
coord.gl(v_or_x: Vec.Vec2 | number, y_or_nil: number | Vec.Vec2?): ScreenPosition
```

Creates a [`ScreenPosition`](/references/master/coord/#screenposition) from screen coordinates.

The origin (0, 0) is the center of the screen, the bottom left is (-1, -1) and the top right is (1, 1). The x axis
goes right and the y axis goes up. The screen is 2 units wide and 2 units high, whatever its shape, so a square of
size (1, 1) is not square on a window that is not square.

This is the system that a [`Vec2`](/references/master/vec/#vec2) uses when you pass it to a drawing function.

**Parameters**

- `v_or_x` (`Vec.Vec2 | number`): The position as a [`Vec2`](/references/master/vec/#vec2), or only its x component when the second argument is the y component.
- `y_or_nil` (`number | Vec.Vec2?`): The y component when the first argument is a number.

**Returns** The position as a [`ScreenPosition`](/references/master/coord/#screenposition).

#### Errors

Raises an error (`"Invalid arguments"`) if the arguments are neither two numbers nor a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const coord = require("@vectarine/coord")
const graphics = require("@vectarine/graphics")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A circle in the upper right quarter of the screen
	graphics.drawCircle(coord.gl(0.5, 0.5), 0.1, vec4.GREEN)
end
```

#### See also

- [`coord.glVec`](/references/master/coord/#coordglvec): a size or distance in screen coordinates.
- [`ScreenPosition:gl`](/references/master/coord/#screenpositiongl): convert back.

### coord.vw

```luau showLineNumbers=false
coord.vw(
	v_or_x: Vec.Vec2 | number,
	screen_size_px_or_y: number | Vec.Vec2?,
	screen_size_px_or_nil: Vec.Vec2?,
): ScreenPosition
```

Creates a [`ScreenPosition`](/references/master/coord/#screenposition) measured in hundredths of the screen width.

The origin is the bottom left of the screen and both axes go up and right (unlike [`coord.px`](/references/master/coord/#coordpx)). One unit is 1% of
the screen width on both axes, so [`coord.vw(50, 0)`](/references/master/coord/#coordvw) is the middle of the bottom edge, and [`coord.vw(10, 10)`](/references/master/coord/#coordvw) is
10% of the width away from the left edge and from the bottom edge, whatever the shape of the window. This name
comes from the CSS unit of the same name.

It takes the same arguments as [`coord.px`](/references/master/coord/#coordpx): two numbers, or a [`Vec2`](/references/master/vec/#vec2), optionally followed by a screen size. By
default the size of the window is used, even while a canvas is being painted.

**Parameters**

- `v_or_x` (`Vec.Vec2 | number`): The position as a [`Vec2`](/references/master/vec/#vec2), or only its x component when the second argument is the y component.
- `screen_size_px_or_y` (`number | Vec.Vec2?`): The y component when the first argument is a number, otherwise the screen size as a [`Vec2`](/references/master/vec/#vec2).
- `screen_size_px_or_nil` (`Vec.Vec2?`): The screen size as a [`Vec2`](/references/master/vec/#vec2), when the first two arguments are numbers.

**Returns** The position as a [`ScreenPosition`](/references/master/coord/#screenposition).

#### Errors

Raises an error (`"Invalid arguments"`) if the first two arguments are neither two numbers nor a [`Vec2`](/references/master/vec/#vec2).

#### Example

```luau
const coord = require("@vectarine/coord")
const graphics = require("@vectarine/graphics")
const vec4 = require("@vectarine/vec4")

function Update(deltaTime: number)
	-- A square whose sides are 10% of the screen width, 5% from the left and bottom edges
	graphics.drawRect(coord.vw(5, 5), coord.vwVec(10, 10), vec4.RED)
end
```

## ScreenVec

```luau showLineNumbers=false
export type ScreenVec = ...
```

A distance or a size on the screen, independent of the coordinate system it was written in.

You get one from [`coord.pxVec`](/references/master/coord/#coordpxvec), [`coord.glVec`](/references/master/coord/#coordglvec), [`coord.vwVec`](/references/master/coord/#coordvwvec) or [`coord.vhVec`](/references/master/coord/#coordvhvec), or by subtracting two
[`ScreenPosition`](/references/master/coord/#screenposition). Add and subtract them with `+` and `-`, scale them with [`ScreenVec:scale`](/references/master/coord/#screenvecscale), and use them
wherever a function expects a size or a direction. Internally it is stored in screen coordinates.

**Operators**

`a + b` — `(a: ScreenVec, b: ScreenVec): ScreenVec`

Adds two [`ScreenVec`](/references/master/coord/#screenvec): `a + b` is the distance covered by walking `a` and then `b`.

`a - b` — `(a: ScreenVec, b: ScreenVec): ScreenVec`

Subtracts two [`ScreenVec`](/references/master/coord/#screenvec): `a - b` is the distance that goes from `b` to `a`.

### ScreenVec:gl

```luau showLineNumbers=false
ScreenVec:gl(): Vec.Vec2
```

Returns the vector as a [`Vec2`](/references/master/vec/#vec2) in screen coordinates.

The whole screen is 2 units wide and 2 units high in this system, and the y axis goes up. No screen size is
needed for this conversion.

**Returns** The vector in screen coordinates.

#### Example

```luau
const coord = require("@vectarine/coord")

local size = coord.glVec(0.5, 0.25)
print(size:gl()) -- the same numbers as a Vec2: 0.5, 0.25
```

### ScreenVec:px

```luau showLineNumbers=false
ScreenVec:px(screen_size: Vec.Vec2?): Vec.Vec2
```

Returns the vector as a [`Vec2`](/references/master/vec/#vec2) in pixels.

The y axis of the result goes down, as for [`coord.px`](/references/master/coord/#coordpx). The pixel size is computed from the size of the window
(in the same units as [`coord.px`](/references/master/coord/#coordpx)), not from the canvas currently being painted, unless you pass `screen_size`.

**Parameters**

- `screen_size` (`Vec.Vec2?`): The size in pixels to convert against, for example the size of a canvas. Defaults to the size of the window.

**Returns** The vector in pixels.

#### Example

```luau
const coord = require("@vectarine/coord")

local size = coord.glVec(0.5, 0.5)
-- In an 800x600 window, a quarter of the width and of the height:
print(size:px()) -- 200, -150
```

### ScreenVec:scale

```luau showLineNumbers=false
ScreenVec:scale(k: number): ScreenVec
```

Returns the vector multiplied by a number.

**Parameters**

- `k` (`number`): The factor. A negative value flips the direction of the vector.

**Returns** A new [`ScreenVec`](/references/master/coord/#screenvec).

#### Example

```luau

```

## ScreenPosition

```luau showLineNumbers=false
export type ScreenPosition = ...
```

A point on the screen, independent of the coordinate system it was written in.

You get one from [`coord.px`](/references/master/coord/#coordpx), [`coord.gl`](/references/master/coord/#coordgl), [`coord.vw`](/references/master/coord/#coordvw) or [`coord.vh`](/references/master/coord/#coordvh), from the constants such as [`coord.CENTER`](/references/master/coord/#coordcenter), or by
adding a [`ScreenVec`](/references/master/coord/#screenvec) to another position. Pass it to any function that draws at a position. Internally it is stored
in screen coordinates. Convert it back with [`ScreenPosition:gl`](/references/master/coord/#screenpositiongl) or [`ScreenPosition:px`](/references/master/coord/#screenpositionpx).

**Operators**

`a + b` — `(a: ScreenPosition, b: ScreenVec): ScreenPosition`

Moves a [`ScreenPosition`](/references/master/coord/#screenposition) by a [`ScreenVec`](/references/master/coord/#screenvec): `position + vector` is the position reached after walking `vector`.

Adding two positions raises an error, since it has no meaning. Subtract them to get a [`ScreenVec`](/references/master/coord/#screenvec) instead.

`a - b` — `((ScreenPosition, ScreenPosition) -> ScreenVec) & ((ScreenPosition, ScreenVec) -> ScreenPosition) & ((ScreenPosition, Vec.Vec2) -> ScreenPosition)`

Subtracts from a [`ScreenPosition`](/references/master/coord/#screenposition). The result depends on the right operand:

- `position - position` is the [`ScreenVec`](/references/master/coord/#screenvec) that goes from the second position to the first one.
- `position - vector` is the [`ScreenPosition`](/references/master/coord/#screenposition) reached by walking back along `vector`.

### ScreenPosition:gl

```luau showLineNumbers=false
ScreenPosition:gl(): Vec.Vec2
```

Returns the position as a [`Vec2`](/references/master/vec/#vec2) in screen coordinates.

In this system, (-1, -1) is the bottom left of the screen, (0, 0) its center and (1, 1) its top right. No screen
size is needed for this conversion.

**Returns** The position in screen coordinates.

#### Example

```luau
const coord = require("@vectarine/coord")

print(coord.TOP_LEFT:gl()) -- -1, 1
```

### ScreenPosition:px

```luau showLineNumbers=false
ScreenPosition:px(screen_size: Vec.Vec2?): Vec.Vec2
```

Returns the position as a [`Vec2`](/references/master/vec/#vec2) in pixels.

The origin (0, 0) is the top left of the screen and the y axis goes down, as for [`coord.px`](/references/master/coord/#coordpx).

**Parameters**

- `screen_size` (`Vec.Vec2?`): The size in pixels to convert against. Defaults to the size of the window, as given by [`io.getWindowSize`](/references/master/io/#iogetwindowsize) (the canvas currently being painted is not used).

**Returns** The position in pixels.

#### Example

```luau

print(coord.BOTTOM_RIGHT:px()) -- 800, 600
```
