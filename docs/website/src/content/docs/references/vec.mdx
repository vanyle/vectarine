Module for 2D vectors.
Because 2D vectors are so common (your screen is 2D!), this module is called [`vec`](/references/vec/) instead of `vec2`.
See [`vec4`](/references/vec4/) for 3D and 4D vectors.

### vec.fromAngle

```luau showLineNumbers=false
vec.fromAngle(angle: number, length: number?): Vec2
```

Create a new 2d vector of length `length` pointing towards the given angle (in radians)
If `length` is not provided, it defaults to 1
This is the same as: `V2(math.cos(angle), math.sin(angle)) * length`
