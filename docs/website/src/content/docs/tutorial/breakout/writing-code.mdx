## The basics of Luau programming

When your game is first loaded, the `game.luau` file is executed. Files ending with `.luau` contain Luau code that is executed to make your game work.

Code is read top to bottom and every line contains something for the computer to do, like a cooking recipe.

### Functions

Code is organized into functions. Functions are reusable pieces of code that do useful things.

export const gettingStartedFuncDef = `function functionName()

-- put content of the function here

end`;

<Code lang="luau" code={gettingStartedFuncDef} />

You can call a function to run it by writing its name followed by parentheses:

export const gettingStartedFuncCall = `functionName()`;

<Code lang="luau" code={gettingStartedFuncCall} />

This will run the content of `functionName`. While you can write and call your own functions, Vectarine and Luau have a lot of functions to do all kinds of things useful for making games like drawing to the screen, playing sound, etc.
A simple example is the `math.abs` function which removes the sign of a number so `math.abs(-3)` is 3 and `math.abs(1.2)` is 1.2.

### Comments

Inside code, you can add explanations that do nothing for the computer but are useful for you to understand and remember what the code does.
These explanations are preceded by `--` and are called comments. You can write anything you want in comments, and they will be ignored by the computer.

export const gettingStartedComment = `-- Hello, I'm explaining the code below.`;

<Code lang="luau" code={gettingStartedComment} />

As this is a tutorial, I will use a lot of comments to explain what is going on all of the time. To help
you distinguish between comments and code, the comments are grayed out.

### The `Update` function

The `Update` function is a special function that is called every frame by Vectarine.
This is where you put the code that needs to be executed continuously, like drawing your game.

Code outside of the `Update` function is executed once at the start of the game and can be used to initialize things.

When you save, Vectarine will re-execute your `game.luau` file to provide hot-reload.

export const gettingStartedUpdateDef = `
-- We define a function named Update. Vectarine tries to call the function named Update every frame.
function Update(deltaTime: number)
	-- This code is executed every frame
end`;

<Code lang="luau" code={gettingStartedUpdateDef} />

This is the smallest valid Vectarine game. It does nothing, but you can add code inside `Update` to draw things.

`deltaTime` is the time in seconds since the last frame. You can use it to make objects move at a consistent speed regardless of how fast the code is executed.

### Modules

Modules are groups of related functions. To get access to a module, you need to *import* it using the `require` function, like so:

export const importingModules = `
const myModule = require("moduleName")
-- To execute a function, you need to put parentheses after its name.
-- Inside these parentheses, you can sometimes put arguments to give the function more information to do its job.
myModule.functionInsideModule()
myModule.functionWithArguments(1, 4, 5)
`;

<Code lang="luau" code={importingModules} />

Vectarine has many modules to do many things. The first modules we'll see are the `debug`, `graphics`, `vec` and `vec4` modules.

- `debug` provides functions for debugging your game.
- `graphics` provides functions to draw on the screen.
- `vec` provides functions to make and modify 2d vectors
- `vec4` provides functions to make and modify 4d vectors, which are used to represent colors.

As the screen is 2D, a lot of *graphics* functions take 2d vectors called `Vec2` as arguments to represent screen locations.

<Aside type='note'>
Variables contain values which have a type.
For example 3 is of type `number`, `"Hello"` is of type `string`, `vec.V2(1, 2)` is of type `Vec2` (2d vector) and `true` and `false` are of type `boolean`.

When we write:

<Code lang="luau" code={gettingStartedUpdateDef} />

We say that the `Update` function takes one argument named `deltaTime` of type number.
Specifying the type of function arguments is optional, but is very helpful to remember what functions want as inputs.

Functions, like `math.abs` can also *return* values. You can think of functions that return values like factories that take some input product
and output a new product. You can also specify the return type like so:

export const addFunction = `
-- We create a function named addPlusTwo that takes 2 numbers as arguments and returns (outputs) a number.
function addPlusTwo(firstInputValue: number, secondInputValue: number): number
	-- Inside the function, we write code that explains how the output is produced using the input arguments.
	-- We write 'return' followed by the value we want to output.
	-- 'return' stops the execution of the function: once the function produced its output, it finished.
	return firstInputValue + secondInputValue + 2
end`;

<Code lang="luau" code={addFunction} />

</Aside>

To be able to use a vectarine function, you first need to *import* the module that contains it using `require("@vectarine/modulename")`,
for example `const debug = require("@vectarine/debug")` to import the `debug` module.

However, to use a built-in Luau module, you don't need to import anything. For example the `math` module is built-in and is thus always available. We
say that the `math` module is part of the *Luau Standard Library*. Other modules of the standard library include `table`, `string` or `bit32`.
`require` is another example of a function from the standard library, as it is always available without needing to import anything.

You can find the list of all built-in modules in the [Luau Standard Library Reference](https://luau.org/library/).

The vectarine modules are not part of the standard library, so you need to import them using `require` to use them.
You can find the list of all vectarine modules and the functions they provide inside the `luau-api` folder of your project.

Reading the list of available functions and their documentation is a good way to learn what you can do with vectarine.

const debug = require("@vectarine/debug")

### Using the graphics module

Now, let's see how to draw a circle on the screen using the `graphics` module. You can copy and paste the following code in your `game.luau` file and save it to see what it does:

export const usingGraphicsModule = `-- We require the graphics, vec and vec4 modules to get access to their functions
const vec = require("@vectarine/vec")
const vec4 = require("@vectarine/vec4")
const graphics = require("@vectarine/graphics")

function Update(deltaTime: number)
	-- We call the clear function from the graphics module to set the background color to white.
	graphics.clear(vec4.WHITE)
	-- We call the drawCircle function from the graphics module to draw a red circle at the center of the screen with a radius of 0.5 units.
	graphics.drawCircle(vec.V2(0, 0), 0.5, vec4.RED)
end`;

### Variables

We can use `variables` to store the results of functions for later use.

You can make a vector using the `vec.V2` function like so:

export const startedVecCreate = `-- Import the vec module to get access to the Vec2 type
const vec = require("@vectarine/vec")

-- Use the vec.V2 function to create a vector with x = 1 and y = 2, and put it in a variable named v
local v = vec.V2(1, 2)`;

<Code lang="luau" code={startedVecCreate} />

We are using the `local` keyword to create a variable named `v` that contains the vector `(1, 2)`. Variables are like boxes that contain values.
The `local` keyword and the `const` keywords are similar, but `const` variables cannot be changed after they are created (we could call them *constants* to be more precise),
while `local` variables can be changed.

export const localKeyword=`
const debug = require("@vectarine/debug")

-- var contains the value 3
local var = 3
-- name contains the value "Joe"
local name = "Joe"

-- var2 contains the value 5 because it is the result of adding 2 to 3.
local var2 = var + 2
-- You can modify the content of a variable by assigning it a new value like so:
-- Now var contains the value 4 because we added 1 to it.
var = var + 1

-- var is shown to the console (this is the same as printing 4)
debug.print(var)
`;

<Code lang="luau" code={localKeyword} />

When requiring a module, we put it into a variable to use all of its functions later which is why we also use the `const` keyword there.

Colors are represented as `vec4` because they are made of a mix of red, green, blue and alpha (opacity).
The `vec4` module contains a few default colors like `vec4.WHITE` and `vec4.RED` but you can also create your own colors with `vec4.createColor(r, g, b, a)` where r, g, b and a are numbers between 0 and 1.

Try to replace the code inside your project with this one, and save the file. You should see a red circle and a blue rectangle on a white background.

export const startedDrawBasic = `-- Import the graphics, vec and vec4 modules
-- modules that start with @vectarine/ are built-in modules provided by Vectarine
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require('@vectarine/vec4')

function Update(deltaTime: number)
	-- Set the background color to white using the clear function
	graphics.clear(vec4.WHITE)

	-- Draw a red circle at the center of the screen (0,0) with a radius of 0.5 units (2 units is the width of the screen)
	graphics.drawCircle(vec.V2(0, 0), 0.5, vec4.RED)

	local rectColor = vec4.createColor(0, 0, 1, 1) -- Create a blue color
	-- Draw a blue rectangle at the bottom right of the screen
	graphics.drawRect(vec.V2(0.7, -1), vec.V2(0.3, 0.3), rectColor)
end`;

<Code lang="luau" code={startedDrawBasic} />

When using Vectors:

- `(0,0)` is the center of the screen.
- `(-1,-1)` is the bottom left of the screen.
- `(-1,1)` is the top left of the screen.
- `(1,-1)` is the bottom right of the screen.
- `(1,1)` is the top right of the screen.

The screen is 2x2 units.

## Quiz

You can quiz yourself to test your understanding. What will these pieces of code do when put inside Vectarine?

export const exampleCodeQuiz1 = `
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require('@vectarine/vec4')

-- What happens if I draw outside of Update?
graphics.drawCircle(vec.V2(0, 0), 0.5, vec4.BLUE)

function Update(deltaTime: number)
    graphics.clear(vec4.WHITE)
    graphics.drawCircle(vec.V2(0, 0), 0.5, vec4.GREEN)
end
`;

<Code lang="luau" title="game.luau" code={exampleCodeQuiz1}/>

<details>
<summary>Solution</summary>
Code outside of Update is for initialization. So, the blue circle gets drawn once and is immediately overwritten by the green circle inside the `Update` function.
Only the green circle is seen on the window.
</details>

export const exampleCodeQuiz2 = `
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require('@vectarine/vec4')

local function magic(size: number)
    graphics.drawCircle(vec.V2(0, 0), size, vec4.BLUE)
end

function Update(deltaTime: number)
    graphics.clear(vec4.WHITE)
    magic(0.2)
end
`;

<Code lang="luau" title="game.luau" code={exampleCodeQuiz2}/>

<details>
<summary>Solution</summary>
We create a function called `magic` which draws a blue circle of the provided size.
Inside Update, we call this function with a size of `0.2`. This will thus draw a blue circle of size 0.2.
</details>


export const exampleCodeQuiz3 = `
const graphics = require("@vectarine/graphics")
const vec = require("@vectarine/vec")
const vec4 = require('@vectarine/vec4')

local time = 0

function Update(deltaTime: number)
    time += deltaTime
    graphics.clear(vec4.WHITE)
    graphics.drawCircle(vec.V2(0, 0), math.cos(time)/10 + 0.2, vec4.RED)	
end
`;

<Code lang="luau" title="game.luau" code={exampleCodeQuiz3}/>

<details>
<summary>Solution</summary>
We create a variable named `time` and set it to 0. On every frame, we increase `time` by the amount of elapsed time, so the time variable
increases on every frame.

Then, we use it to draw a red circle of size `math.cos(time)/10 + 0.2`. Remember that `cos` is a function returning values between `-1` and `1`, so this will
draw a circle with a size between `-1/10 + 0.2 = 0.1` and `1/10 + 0.2 = 0.3`. As `cos` is smooth, the size of the circle will smoothly animate between `0.1` and `0.3`.
</details>
