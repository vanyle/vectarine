In this step-by-step tutorial, we'll see how you can create your first game using Vectarine.
This will be a *Breakout*-style game (also called a brick breaker), where you control a paddle to bounce a ball and break bricks.

The whole tutorial takes about 3 hours, and you don't need to know anything about programming to follow it.

Along the way, you'll learn:

- How to write programs using the same tools as professional game devs.
- Basic game dev concepts, like drawing graphics, working with coordinates, handling sound, physics, ...
- Basic game design concepts, like juice and UX.
- How to use Vectarine to quickly build games and prototypes.

You can play the finished version of the game to see what the result will look like. Use the arrow keys and <Kbd windows="Space" mac="Space"/>, or press the left and right sides of the screen on a phone:
